# 板块轮动模型系统知识库

## 1. 系统整体架构描述

板块轮动模型系统是基于板块特征的选股策略系统，使用板块和大盘特征进行训练，结合长短周期捕捉轮动特征，支持使用LNN(液体神经网络)模型更好地反映时间序列特征。核心思想是基于板块表现预测，选择表现最好的板块，再从中选择最优股票。

### 架构分层

系统架构采用分层设计，主要包括以下几层：

1. **数据获取层**：负责从数据源获取原始数据，包括股票行情、板块成分等
2. **数据处理层**：负责清洗、转换原始数据，生成特征
3. **特征存储层**：负责高效存储和管理生成的特征
4. **模型层**：负责训练和应用各种预测模型
5. **信号生成层**：根据模型输出生成交易信号
6. **运行工具层**：提供各种运行和管理工具

### 核心概念

1. **板块轮动**：通过识别市场中强势板块的轮换，把握市场热点
2. **多周期特征**：结合短期(5-30天)和长期(60-90天)特征，全面捕捉市场趋势
3. **时间衰减权重**：近期样本权重更高，使模型更关注近期市场变化
4. **液体神经网络**：适合时间序列数据的神经网络架构，能够更好地捕捉市场变化

## 2. 已实现组件清单及其功能

### 2.1 核心组件

#### 数据加载组件

1. **`advanced_quant_data.py`**
   - 实现`ParquetDataStorage`类，提供高效的数据存储和访问
   - 实现行情数据下载、存储和管理功能
   - 提供交易日历管理功能

2. **`data_loaders.py`**
   - 实现各种数据加载器接口
   - 支持从不同数据源加载数据
   - 提供数据格式转换功能

3. **`stock_sectors_mapping.py`**
   - 管理股票与板块之间的映射关系
   - 提供板块成分股查询功能
   - 支持自动更新板块映射数据

#### 特征生成组件

1. **`generate_sector_features.py`**
   - 生成板块级别的特征
   - 支持增量更新和全量更新
   - 实现特征合并和优化功能

2. **`vectorized_features.py`**
   - 实现向量化的特征提取，提高计算效率
   - 提供批量特征计算功能
   - 实现各种技术指标的快速计算

3. **`sector_analysis.py`**
   - 提供板块分析功能
   - 计算板块内股票的涨跌幅排名
   - 支持板块轮动分析

4. **`stock_daily_rankings.py`**
   - 计算股票日线数据的各种排名
   - 支持涨幅榜、跌幅榜、成交额榜等

#### 模型组件

1. **`train_models.py`**
   - 实现模型训练的核心功能
   - 支持多种模型训练策略
   - 实现特征加载、数据准备、模型保存等功能

2. **`Liquid/nn/liquid/liquid_network.py`**
   - 实现液体神经网络
   - 提供时间序列建模能力
   - 支持可学习的时间常数和非线性激活

3. **`model_classes.py`**
   - 实现各种模型类
   - 提供模型集成功能
   - 支持模型保存和加载

#### 运行组件

1. **`simple_runner.py`**
   - 提供简易的模型运行接口
   - 支持命令行参数配置
   - 实现单日和日期范围处理

2. **`incremental_training.py`**
   - 实现增量训练功能
   - 提高训练效率
   - 支持模型更新

3. **`numba_accelerator.py`**
   - 提供计算加速功能
   - 加速各种技术指标计算
   - 提高回测速度

### 2.2 辅助组件

1. **`config.py`**
   - 管理系统配置
   - 定义路径和常量
   - 提供配置访问接口

2. **`create_data_directories.py`**
   - 创建系统所需的数据目录
   - 确保目录结构正确
   - 初始化系统环境

3. **`market_status_processor.py`**
   - 处理市场状态数据
   - 分析市场环境
   - 为模型训练提供市场上下文

4. **`test_sector_rotation.py`**
   - 测试板块轮动模型
   - 验证模型功能
   - 提供示例用法

   - 特征生成组件依赖数据加载组件获取原始数据

   - 模型训练依赖于特征生成组件的输出

   - 多个组件依赖`stock_sectors_mapping.py`获取板块与股票的关系
   - 特征生成和信号生成都需要板块映射信息

4. **配置依赖**
   - 几乎所有组件都依赖`config.py`获取系统配置
   - 路径、参数等配置集中管理

5. **模型依赖**
   - 运行组件依赖模型组件执行具体的预测逻辑
   - 高级模型依赖基础模型组件

## 4. 数据流向说明

整个系统的数据流向可分为以下几个阶段：

### 4.1 数据采集阶段

1. 数据源 → 数据加载器
   - 从外部数据源(如xtquant.xtdata)获取股票行情数据
   - 获取板块成分股数据
   - 获取交易日历数据

2. 数据加载器 → 本地存储
   - 将原始数据保存为Parquet格式
   - 按日期和类型组织数据
   - 处理增量数据更新

### 4.2 特征生成阶段

1. 原始数据 → 板块特征
   - 生成板块级别的技术指标
   - 计算板块内股票的统计特征
   - 保存到`local_data/sector_features`目录

2. 原始数据 → 个股特征
   - 计算个股的技术指标
   - 生成相对强度、资金流向等特征
   - 保存到`local_data/features`目录

3. 原始数据 → 市场特征
   - 计算大盘指标
   - 生成市场状态特征
   - 保存到`local_data/market_features`目录

### 4.3 模型训练阶段

1. 特征数据 → 训练数据集
   - 加载板块、个股和市场特征
   - 按照长短周期划分
   - 添加时间衰减权重
   - 构建样本特征和标签

2. 训练数据集 → 模型
   - 训练液体神经网络(LNN)和传统模型
   - 模型集成
   - 保存训练好的模型到`models`目录

### 4.4 预测与信号生成阶段

1. 特征数据 + 模型 → 板块预测
   - 对未来表现进行预测
   - 对板块进行排名
   - 选择表现最好的板块

2. 板块预测 + 个股特征 → 股票选择
   - 从预测的板块中选择最优个股
   - 计算个股权重
   - 生成交易信号

3. 交易信号 → 输出
   - 保存交易信号到文件
   - 提供接口访问信号
   - 可视化分析结果

## 5. 系统使用流程

### 5.1 基本使用流程

1. **数据准备**
   - 确保交易数据已下载
   - 确保板块映射数据已更新

2. **特征生成**
   - 生成板块特征
   - 生成市场特征

3. **模型训练**
   - 选择训练日期范围
   - 设置长短周期参数
   - 指定是否使用LNN模型

4. **生成交易信号**
   - 指定目标日期
   - 设置选股参数
   - 运行生成交易信号

### 5.2 命令行示例

```bash
# 生成板块特征
python -m to.generate_sector_features --start_date 20230101 --end_date 20230331

# 训练模型并生成信号
python -m to.simple_runner --date 20230105 --lookback_short 30 --lookback_long 90 --use_lnn

# 处理一段时间范围
python -m to.simple_runner --start_date 20230101 --end_date 20230110
```

## 6. 最佳实践

1. **数据管理**
   - 定期更新板块映射数据
   - 使用增量更新减少计算量
   - 合理设置缓存大小

2. **特征计算**
   - 使用向量化计算提高效率
   - 优先使用Parquet格式存储特征
   - 利用多进程加速大批量计算

3. **模型训练**
   - 使用时间衰减权重重视近期数据
   - 结合长短周期特征提高预测准确性
   - 定期更新模型保持时效性

4. **系统运行**
   - 使用配置文件管理参数
   - 根据市场状态调整模型参数
   - 记录完整日志便于分析问题
