# 模型训练与股票选择说明

## 1. 模型训练的整体逻辑

`train_models.py`是量化交易系统中的核心组件，专门用于训练板块特征模型，并生成交易信号。主要流程如下：

1. **数据加载**: 从特征文件中加载板块特征数据
2. **特征处理**: 对原始特征进行选择和处理，准备训练数据
3. **标签生成**: 基于历史数据和市场状态生成训练标签
4. **模型训练**: 使用特征和标签训练机器学习模型
5. **模型保存**: 将训练好的模型保存到磁盘，供后续回测和实盘使用
6. **股票选择**: 基于模型预测和其他筛选指标选择最优股票
7. **交易信号生成**: 为选中的股票生成具体交易信号

系统支持多线程并行训练，可以高效训练多个板块的模型，并可选择性地使用GPU加速以提高训练效率。

## 2. 相关代码文件

### 核心文件

- **train_models.py**: 模型训练的主脚本，包含特征加载、模型训练和交易信号生成的核心逻辑
- **model_classes.py**: 定义了各种模型类，包括EnsembleModel等集成模型
- **sector_loader.py**: 提供板块特征数据的加载功能
- **market_status_features.py**: 提供市场状态特征的加载和处理功能

### 辅助文件

- **stock_sectors_mapping.py**: 提供股票与板块的映射关系
- **generate_sector_features.py**: 生成板块特征的脚本
- **train_accelerator.py**: 提供训练加速功能（可选）
- **numba_accelerator.py**: 基于Numba的计算加速工具（可选）

## 3. 主要类和方法

### 主要类

- **EnsembleModel**: 集成多种机器学习模型进行预测
- **LiquidNetModel**: 基于液体时间网络的高级时序模型
- **SimpleParquetDataStorage**: 简化版数据存储类，用于读取交易日历和股票数据

### 关键方法

- `train_with_sector_features(sector_name, date, model_dir, ...)`: 使用板块特征训练单个板块的模型
- `_load_sector_features(start_date, end_date, feature_dir)`: 加载板块特征数据
- `_load_market_features(start_date, end_date, index_code)`: 加载大盘指数特征
- `train_sector_models(sectors, date, ...)`: 训练多个板块的模型
- `_select_top_stocks_in_sector(sector_name, sector_stocks, date, top_n)`: 在板块内选择表现最好的股票
- `_calculate_relative_strength(stocks, start_date, end_date)`: 计算股票相对强度得分
- `generate_signals_from_models(sectors, date, ...)`: 基于模型生成交易信号

## 4. 运行参数说明

`train_models.py`脚本支持多种命令行参数，用于控制模型训练和信号生成的行为：

```
python train_models.py [参数]
```

### 主要参数

- `--date`: 指定单个训练日期，格式为YYYYMMDD
- `--start_date`: 开始日期，格式为YYYYMMDD
- `--end_date`: 结束日期，格式为YYYYMMDD
- `--interval`: 日期间隔，默认为1天
- `--sectors`: 要处理的板块列表，多个板块用逗号分隔
- `--lookback_short`: 短期回溯天数，默认30
- `--lookback_long`: 长期回溯天数，默认90
- `--forward_days`: 预测未来几天，默认5
- `--feature_dir`: 特征数据目录
- `--model_dir`: 模型保存目录
- `--workers`: 并行工作进程数，默认1
- `--use_accelerator`: 是否使用GPU加速

### 板块轮动相关参数

- `--sector_rotation`: 使用板块轮动模式训练模型
- `--use_lnn`: 使用LNN模型进行时间序列建模
- `--top_sectors`: 选择排名靠前的板块数量，默认3
- `--stocks_per_sector`: 每个板块选择的股票数量，默认3
- `--generate_signals`: 生成个股交易信号
- `--signal_dir`: 交易信号保存目录，默认"to/signals"

### 参数使用示例

```bash
# 为特定日期训练所有板块模型
python train_models.py --date 20230630 --model_dir to/models

# 训练日期范围内的特定板块模型，使用4个工作进程
python train_models.py --start_date 20230101 --end_date 20230630 --sectors TGN人工智能,TGN5G --workers 4

# 使用板块轮动模式，选择前5个板块的前3只股票，并生成交易信号
python train_models.py --date 20230630 --sector_rotation --top_sectors 5 --stocks_per_sector 3 --generate_signals
```

## 5. 模型文件存储结构

训练好的模型文件存储在以下目录结构中：

```
/to/models/
├── TGN人工智能/
│   ├── 20230101.pkl        # 模型文件，按训练日期命名
│   ├── 20230201.pkl
│   └── ...
├── TGN5G/
│   ├── 20230101.pkl
│   └── ...
└── ...
```

每个模型文件（.pkl）包含以下内容：
- 训练好的模型实例
- 训练日期
- 板块名称
- 使用的特征列表

## 6. 交易信号格式

如果开启了信号生成功能，系统会在指定目录生成如下结构的交易信号文件：

```
/to/signals/
├── 20230630/
│   ├── signals.json        # 所有信号汇总
│   ├── signals_TGN人工智能.json  # 特定板块的信号
│   └── ...
└── ...
```

信号文件采用JSON格式，包含以下信息：
- 股票代码
- 买入/卖出信号类型
- 建议价格
- 止损价格
- 目标价格
- 来源板块
- 预测置信度

## 7. 股票选择策略

系统采用多因子综合评分方法选择最优股票：

1. **相对强度因子** (权重35%): 衡量股票相对于其他股票的价格表现
2. **资金流入因子** (权重25%): 衡量近期流入股票的资金情况
3. **技术指标因子** (权重25%): 基于MACD、RSI等技术指标的综合评分
4. **成交量特征因子** (权重15%): 衡量交易活跃度和市场关注度

对每个板块内的股票按照综合得分排序，选择分数最高的若干只股票。

## 8. 模型类型与特点

系统支持多种模型，并采用集成学习方法提高预测稳定性：

1. **随机森林**: 对处理非线性关系有较好效果，适合小样本量
2. **XGBoost**: 梯度提升树模型，具有高准确率和抗过拟合能力
3. **LightGBM**: 轻量级梯度提升树，训练速度更快
4. **CatBoost**: 更好地处理类别特征，自动处理缺失值
5. **液体神经网络(LNN)**: 专为时间序列数据设计的高级神经网络模型

集成模型采用软投票策略整合各模型的预测结果，提高预测稳健性。

## 9. 注意事项与最佳实践

1. **数据准备**:
   - 确保板块特征数据已经生成并存储在正确的位置
   - 特征数据的时间跨度应足够长，至少覆盖`lookback_long`指定的天数

2. **模型训练优化**:
   - 调整`--workers`参数可以充分利用多核处理器提高训练速度
   - 对于大型模型，启用`--use_accelerator`可显著提高训练速度
   - 定期重新训练模型以适应市场变化，建议每1-3个月一次

3. **信号生成**:
   - 交易信号仅供参考，实际交易时应结合其他分析
   - 调整`--top_sectors`和`--stocks_per_sector`可以控制投资分散度
   - 对于风险偏好低的策略，可以增加板块数量，减少每个板块选择的股票数量

4. **错误处理**:
   - 系统设计了完善的错误处理机制，对单个板块或日期的处理失败不会影响整体流程
   - 查看日志文件可以了解详细的训练过程和可能的错误原因

5. **内存管理**:
   - 处理大量数据和多模型训练时，注意监控内存使用情况
   - 系统会自动调用垃圾回收，但对于特别长的训练任务，建议分批进行
