# 全新机器学习选股系统

## 设计理念
- **简单直接**：避免过度复杂的嵌套分类器
- **数据驱动**：基于实际数据特征进行状态分类
- **模块化**：每个模块职责单一，易于调试
- **可验证**：每个步骤都有清晰的输出和验证

## 系统架构

### 1. 数据加载模块 (data_loader.py)
- 复用现有的数据加载逻辑
- 加载个股、板块、市场特征数据

### 2. 特征工程模块 (feature_engineer.py)
- 基于文档规范处理特征
- 生成板块状态所需的关键特征

### 3. 状态分类模块 (state_classifier.py)
- **简化设计**：直接基于特征阈值进行状态分类
- **16个子状态**：确保所有子状态都能被正确生成
- **可调试**：每个状态的生成逻辑都清晰可见

### 4. 选股模块 (stock_selector.py)
- 基于板块状态进行选股
- 重点关注两个最佳子状态：rising_leading_breakout 和 retreat_orderly_retreat

### 5. 评估模块 (evaluator.py)
- 计算收益率、最大回撤、胜率等指标
- 生成详细的分析报告

## 核心原则
1. **先让系统跑起来**：确保16个子状态都能正确生成
2. **再优化性能**：在基础功能稳定后进行优化
3. **数据验证**：每个步骤都验证数据的正确性
4. **日志详细**：便于问题定位和调试
