# 标签配置参数修改说明

## 修改内容

已将 `allocate_labels_daily` 函数中的硬编码标签数量参数提取为可配置变量：

### 原来的硬编码
```python
target_30 = min(20, len(sorted_indices))   # 标签30: 固定20只
target_20 = min(40, len(remaining_after_30))  # 标签20: 固定40只
target_10 = min(60, len(remaining_after_20))  # 标签10: 固定60只
```

### 现在的可配置变量
```python
# 🔧 可配置的标签样本数量参数
# 可以直接修改这些数值来调整各标签对应的样本数量：
TARGET_COUNT_30 = 20  # 标签30对应的最大样本数量（推荐范围：10-30）
TARGET_COUNT_20 = 40  # 标签20对应的最大样本数量（推荐范围：30-50）
TARGET_COUNT_10 = 60  # 标签10对应的最大样本数量（推荐范围：50-80）
# 注意：建议保持 TARGET_COUNT_30 <= TARGET_COUNT_20 <= TARGET_COUNT_10 的关系
```

## 使用方法

1. **定位参数**：在 `main.py` 中搜索 `TARGET_COUNT_` 即可找到配置参数

2. **修改数量**：直接修改这三个变量的值：
   ```python
   TARGET_COUNT_30 = 15  # 修改标签30为15只股票
   TARGET_COUNT_20 = 35  # 修改标签20为35只股票
   TARGET_COUNT_10 = 55  # 修改标签10为55只股票
   ```

3. **重新训练**：修改后重新运行模型训练即可生效

## 测试结果

通过测试验证了修改的正确性：

### 测试用例1：充足候选股票 (200只)
- 标签30: 20只 (期望: 20) ✓
- 标签20: 40只 (期望: 40) ✓
- 标签10: 60只 (期望: 60) ✓
- 其他标签: 80只

### 测试用例2：候选股票不足 (80只)
- 标签30: 20只 (期望: 20, 按min分配) ✓
- 标签20: 40只 (期望: 40, 按min分配) ✓
- 标签10: 20只 (期望: 60, 按min分配) ✓
- 其他标签: 0只

### 测试用例3：自定义配置测试
- 自定义配置: 标签30=15, 标签20=30, 标签10=45
- 实际分配: 标签30=15只, 标签20=30只, 标签10=45只 ✓

## 注意事项

1. **数量关系**：建议保持 `TARGET_COUNT_30 <= TARGET_COUNT_20 <= TARGET_COUNT_10`
2. **总量控制**：三个标签的总数不应超过每日候选股票的典型数量
3. **质量保证**：原有的质量筛选逻辑（排除亏损超过8%的股票等）保持不变
4. **灵活性**：如果候选股票不足，系统会自动按`min()`函数进行调整
