## 0. 为什么需要这份架构（问题陈述）

现状三层：
- Candidate Registry 393（零删除）
- Initial Pool 228（有值、卫生 0 剔除）→ Layer-1 信息层删 6 → **工作池候选基 222**
- CURATED 71（模型实际在用，未动）

已尝试并**失败或无效**的精简路径（不得重复）：

| 路径 | 结果 | 失败根因（已诊断） |
|---|---|---|
| 金融直觉 + 因子测试 IC 门 | 随机性高 | 单因子无条件边际统计 ≠ 模型内贡献 |
| 因子测试 + 相关性 | 效果差 | 线性相关只抓等价类，抓不到非线性冗余与互补结构 |
| gain 阈值删减 | 无效 | gain 在强相关因子间随机分配（分裂功劳），小 gain ≠ 无用 |
| 组置换审计（旧版） | 会误杀 37 个市场因子 | 广播列用日内置换 → d≡0 结构性错误 |
| 组置换审计 v2（修复版） | 3 候选 → 验证失败 | 筛选有效（203 簇→3），但**单次重训对比无区分力** |
| Layer-1 信息层（|ρ|≥0.95 等价） | 删 6（有效但量太小） | 门槛只抓"几乎等价"，阈值太低 |

**核心障碍（本架构要解决的真问题）**：
`feature_fraction<1` + `deterministic=True` + `LGB_SEED=42` ⇒ 特征集变一个列，**全树轨迹改变**。
已实证：删 3 个置换零影响因子（其中 2 个 gain=0/split=0，模型从未使用），
H15S champ 0.0068→0.0010。即：**单次重训 Δ 无法归因于被删因子**。

因此本架构的核心不是"再找一个更准的筛选器"，而是：
1. 用**统计检验**（零分布）替代**单点阈值**；
2. 用**噪声带**（同池换种子）标定"多大 Δ 才有意义"；
3. 用**组级候选 + 双容量**做最终裁决，而非单因子。

## 3. Null Importance 协议（本轮主力，用户点 5）

**原理**（回答用户"我不太懂原理"）：
树模型的 gain 不管标签是什么都能拿到分——222 个特征里总有些能拟合噪声。
所以单看 gain 高低没有意义。正确做法是问：
**"如果标签是随机的，这个特征还能拿到这么多 gain 吗？"**

流程：
1. 用真实标签训练基线模型 → 每特征真实 gain `g_real`（已有：base_H15S/importance.csv）
2. 把训练集标签**随机打乱**（K 次，不同 seed）→ 重训 K 次 → 每特征 gain 零分布 `g_null`
3. 判定：`g_real < percentile(g_null, 95)` → **该特征的 gain 无法与噪声区分** → 删除候选

**为什么这比单点阈值强**：
- 自动处理"222 个特征里总有些能拟合噪声"的基线漂移
- 每特征有自己的零分布（不同特征被随机挑中的概率不同），比全局阈值公平
- K 次打乱给出的是**分布**，不是单点

**本轮参数（冻结）**：
- K = 10 次打乱标签（每容量）
- 容量：H15S + H14（与 v2 审计同口径）
- 折：全 6 折（与基线 importance.csv 对齐）
- 判定阈值：95 分位（预注册）
- 注意：打乱标签后模型无预测力，但仍会分配 gain——这正是我们要的零分布

**已知局限（诚实声明）**：
- gain 在强相关因子间随机分配：若 A/B 高度相关，真实标签下 A 或 B 拿 60% gain，
  零分布下二者期望 gain 都很低（都<95分位）→ **可能同时误判二者"可删"**。
  → 因此 null importance 只能提候选（E2），删除必须走 E3 组级裁决。
- 单容量结论不外推：两容量一致才进候选。

**零分布校准前置检查（2026-10-01 冒烟发现后补入，硬性）**：
null importance 成立的前提是"模型在随机标签下**也能**拟合噪声"。
若某容量在打乱标签下训不出任何分裂（零分布退化），则 `real < p95` 恒不成立，
判定会给出假阴性（H14 实测：打乱标签后总 gain=0.0、0 个特征拿到分）。

因此每个容量在出结论前必须先过校准门：
| 校准指标 | 阈值（预注册） | 理由 |
|---|---|---|
| 打乱标签后总 gain 之和 | > 0 | 绝对下限：零分布不能全 0 |
| 打乱标签后拿到 gain 的特征数 | ≥ 池规模的 20% | 零分布需覆盖足够广的因子 |
| 零分布 p95 与真实 gain 中位之比 | 落在 [0.01, 1.0] | 零分布须显著低于真实、但同量级 |

未过校准门的容量：**该容量不出 null importance 结论**，只作 E1 参考。
（实测：H15S 通过；H14 因 127叶+重正则+轮数不足而退化 → 需提高轮数或换口径重测。）

**H14 零分布退化根因（2026-10-01 诊断确认，非轮数问题）**：
单折实测，H14 在 120/300/600 轮下打乱标签**均训不出任何分裂**（gain 恒为 0）。
根因链：H14 = 127叶 + reg_alpha=25/reg_lambda=40（重正则）+ scale_pos_weight=48；
打乱标签后正类率仅 2.5% → 重正则下"任何分裂的 gain 都不值得付出正则代价"
→ LightGBM 直接不分裂。**这是 H14 部署容量的强稀疏化设计所致**，
反过来也说明 H14 本身是一个"只用极少量特征"的模型（与 222 大池 + H14 的
champ 偏好浅树结论一致）。

⇒ **决策（预注册 §3 执行结论）**：null importance 的零分布判定**只在 H15S 出结论**；
H14 因零分布退化**不参与 null 判定**，仅作 E1（真实 gain）参考与 E3 组级裁决容量。
这不削弱架构——H15S 提供了健康的零分布，H14 仍用于组级裁决的第二容量。

## 4. CMIM/JMI 倒退筛选协议（用户点 8）

**原理**：
MI(X;Y) 只看边际；CMIM 用 `I(X;Y|Z)` 问"给定核心 Z 后，X 还有多少独有信息"。
若 `I(X;Y|Z) / I(X;Y) < 10%`（即核心已解释 X 的 90%+ 信息），则 X 近乎冗余。

**本轮参数（冻结）**：
- 核心 Z = 按 base gain 排名前 20 的因子（代表模型实际主力）
- 判据：`min over z∈Z of I(X;Y|z) / I(X;Y) < 0.1` → CMIM 出局
- JMI = I((X,Z);Y) 联合，用于补充排序
- 复用 `pandaai_online/merge/nonlinear.py` 的 `_binned_cond_mi` / `_binned_joint_mi`（已验证口径）

**局限**：分箱 MI 在 4M 行上对 z 的估计有噪声；z 只取 20 个（不是全池）；
仅 E1 证据（虽强于边际 MI，但仍是边际视角）。

## 5. 种子噪声带协议（本架构的裁决标尺，用户点 6 的"合适门槛"）

**这是本架构最重要的新增量**。

**原理**：`LGB_SEED=42` 同时控制 `random_state/bagging_seed/feature_fraction_seed/
data_random_seed/drop_seed`。同池换种子 = 同分布不同抽样轨迹。
若同池换种子产生的 champ 波动是 ±X，则**任何小于 X 的 Δ 都不能作为删除依据**。

**本轮参数（冻结）**：
- 池：BASE222（未删任何因子）
- 种子：42（已有基线） + 7 + 20250930（新增 2 个）
- 容量：H15S + H14
- 输出：每容量的 `champ_score` 分布 → 噪声带 = [min, max] 或 mean±std

**裁决规则（冻结）**：
> 候选组删除后的 Δchamp 若落在噪声带内 → **判"不可区分"**，不删（保守）。
> 若 Δchamp 明显低于噪声带下沿 → 判"真实变坏"，**否决删除**。
> 若 Δchamp 明显高于噪声带上沿 → 判"真实变好"，采纳删除。

### 5.1 噪声带实测结果（2026-10-01，BASE222 三种子双容量）

| 容量 | 种子数 | champ 带宽 min | 带宽 均值 | 带宽 max |
|---|---|---|---|---|
| H15S | 3 (42/7/20250930) | 0.002795 | **0.007490** | 0.014147 |
| H14 | 3 (42/7/20250930) | 0.000606 | **0.006890** | 0.016226 |

**对 Layer-2 的定量判决（架构的诞生依据）**：
- Layer-2 删 3 个置换零影响因子，H15S champ Δ = 0.0068 − 0.0010 = **−0.0058**
- H15S 同池换种子噪声带 = [0.0028, 0.0141]，均值 0.0075
- 判定：**|Δ| = 0.0058 < 带宽均值 0.0075 → Δ 完全落在噪声带内**
  ⇒ Layer-2 的"删了就变差"**不是被删因子的功劳，而是换了一次训练抽签**。

**由此得出的硬性门槛（v1.0 核心结论，冻结）**：
> **单次重训对比对因子增删没有统计功效。** 222 因子规模下，
> 噪声带（±0.007~0.014 champ）比任何小规模删减的真实效应（≈0）大一个数量级。
> 因此：
> 1. 任何**单次**重训 Δ 不得作为删除依据（无论正负）；
> 2. 删减裁决必须**多种子分布判定**（每臂 N 个 seed，比较分布而非点估计）；
> 3. 或者，删除效应必须**大到超出噪声带上沿**（≈+0.014 champ）才可采信——
>    而这种量级的"变好"在实测中从未出现（112 池、50 池对比均无此量级）。
> 4. **推论**：模型层小规模精简在本项目**不可验证**；
>    唯一可安全执行的是"信息层等价删除"（Layer-1 式，|ρ|≥0.95），
>    因为它的正确性不依赖模型重训，而依赖信息等价本身。

## 5.2 多种子门裁决结果（S3 候选，2026-10-01）— 决定性负结果

候选（S3_core，双独立方法收敛）：`close_below_ma5_after_runup`、`limit_down_3d`、
`low_break_prev_low_after_runup`（222→219）。协议：3 种子 × H15S/H14，逐种子配对
Δchamp（test − base）。

| 容量 | seed7 | seed42 | seed20250930 | Δ均值 | Δstd | 正/负 | 判定 |
|---|---|---|---|---|---|---|---|
| H15S | -0.00796 | -0.00578 | -0.00132 | **-0.005023** | 0.00338 | **0 正 / 3 负** | **真实变坏** |
| H14 | +0.00261 | -0.00087 | +0.00194 | +0.001227 | 0.00184 | 2 正 / 1 负 | 不可区分 |

**判别升级——方向一致性（v1.0 新增判据，优于单纯带宽）**：
噪声是**双向对称**的（同池换种子 → Δ 正负混合）；真实效应是**方向一致**的。
- H15S **3/3 全负、零正例** ⇒ 稳定变坏，非随机 → **否决删除**
- H14 正负混合（2正1负）⇒ 纯噪声 → 不构成任何方向的证据

**对 Layer-2 的追认**：Layer-2 单种子（seed42）Δ=-0.0058 看似变坏，现多种子证实
H15S 下 3/3 同向为负 ⇒ **Layer-2 的否决是正确的**，且比当时的单种子证据强得多。

**机制解读（诚实）**：这 3 个因子在 H15S 几乎惰性（gain=0、置换 d=0），却仍致稳定
小幅下降。最合理解释：H15S（15叶 + feature_fraction=0.5）下，模型"被采样到某列就有
边际贡献"，删列改变采样轨迹分布 → 小但方向稳定的效应。这是**采样轨迹效应**，不是
信息效应——但对"是否可删"而言，效应真实存在即为不可删。

⇒ **最终裁决：219 池 REJECTED（多种子证据），工作池维持 BASE222。**

## 11. 前提修正（用户观点，采纳）

用户明确：**模型必须感知全部机制**（趋势/换手/beta/波动/反转/事件/市场门控…），

因此 v1.0 §6 的"机制族分组删除"作废，替换为：
**用筛选器定位杂质 → 杂质成组 → 成组做删除实验（E3 门裁决）。**
分组依据从"机制族"改为"**筛选器判定为杂质**"，机制族只作为**归因标签**
（报告里说明每个杂质属于哪个机制，便于解释，但不决定分组）。

## 12. 组A：CMIM/JMI 杂质筛选（用户点 8 首次用于精简）

### 12.1 主判据与阈值（冻结）

> **[2026-10-01 实证修正，详见 §12.3]** 原定 `min_z I(Y;X|z)/I(Y;X) < τ` 判据在本池
> **失效**（ratio 普遍偏低、τ=0.1 误抓 195/222）。改用 **JMI 主判据 + 平台检测**。

- CMIM 判据（保留作诊断）：`r_f = min_{z∈Z} I(Y;X|z) / I(Y;X)`，核心 Z = gain top20。
- **JMI 主判据（实际采用）**：`jmi_sum = Σ_{z∈Z} I((X,Z);Y)`（Brown 2012 联合MI，
  测互补性）。`jmi_sum` 低 = 与核心"既无互补也无独立信息" = 真杂质。
- **组A 判定（平台检测，无任意阈值）**：`jmi_sum` 的**最小重复平台**
  （`mi≈0` 使 JMI 退化为同值）∪ 紧邻者补至目标体量 8。

## 14. 删除实验：容量与种子设计（v1.1，按用户意见改）

1. H12(31叶)、H8(127叶,轻正则)是现役/主力部署配置；H15S(15叶)覆盖超多因子浅树端。

### 14.1 裁决规则（跨 6 单元，冻结）
对每个单元 (cap,seed)：Δ = test_champ − base_champ（同 seed 配对）。
设 f_neg = Δ<0 的单元比例，meanΔ = 全部 6 单元 Δ 均值，TOL_champ=0.001。
- **否决删除（判有害）**：f_neg ≥ 1/2 且 meanΔ < −TOL。
  （对应 S3 实测：H15S 3/3 全负、mean −0.005 → 判有害。）
- **采纳删除（判无害）**：meanΔ ≥ −TOL 且 f_neg ≤ 1/3。
- **模糊**（介于两者之间）：默认**保留**（保守）；算力允许时补种子重判。
- 采纳后仍需**冻结窗 deploy 复核**才正式落地。

### 20.5 我方 NMI 实现的两处缺陷（自查发现，已修正）
1. **稀疏判定用 `x>0`**：对**恒负连续因子**（回撤类，值域 -0.35~0）会全部归入
   "未触发"箱 -> NMI=0 误伤（close_to_high_3d_mean t=5.43、
   high_to_close_drawdown t=3.42、pullback_depth_from_10d_high t=2.19 全被误报 0）。
   修正：稀疏判定改用 `unique/rows < 0.001`，稀疏分箱改用中位数二分（不假设符号）。
2. **月末截面 + 等频分箱**（v1）：对 2.65% 稀疏二值因子退化。修正：每日全量截面
   + 稀疏中位数二分。
修正后稀疏因子 NMI 不再退化（close_below=1e-5、b_touch=4.2e-4）。

**教训（写入 skill）**：任何自研 MI/分箱实现，必须用"已知强信号因子 + 已知
连续因子"双向自检——恒负因子、恒正因子、二值稀疏因子、连续多值因子各取一例，
验证指标不退化。
