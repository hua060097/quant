**用户的直觉被证实了一半，而且两个方向的"直觉答案"都是错的——问题出在测量仪器本身。**

| 命题 | 判定 | 证据 |
|---|---|---|
| "54 个候选里有大量重复" | **未证实**（定义层 0 重复、激活层 0 重复） | §3.1/§3.3 |

**⇒ 首要缺陷不是"搜索空间冗余"，而是"项目没有预先规定的、经验证的冗余判据"。**
在判据被预先规定并验证之前，任何"该删/该留"的结论都是仪器产物。

## 2. 任务二：已有去冗余能力核对（两条线对照）

### 2.1 能力清单

| 去冗余层 | 进化搜索线（grammar） | 门控搜索线 | 缺口 |
|---|---|---|---|
| ① 语法等价（表达式指纹） | `expression_hash` 规范化 | `gate_ledger.candidate_fp` = spec 元组 | 门控侧无"表达式"概念，仅 spec 元组 |
| ② 结构近克隆 | `structural_fingerprint`（struct_fp） | **`family_fp` = sha1(level\|base)** | ⚠ 门控侧只到"同基础量"粒度，**未到操作化粒度** |
| ③ 值等价 | `value_fingerprint`（vfp） | **`gate_value_fp`（已实现，`reject_vfp` 已接线）** | ⚠ **对 rank 归一化序列退化**（§3.2） |
| ④ 语义检查 | `lint`（语义规则库） | 规格合法性 + 尘埃检测 | 门控侧无经济语义 lint（合理，门控是状态量） |
| ⑤ 稀疏性 | 稀疏/并列告警 | 稀疏性告警（不设门） | 一致 |
| ⑥ **效应相似**（ΔIC 向量） | **无** | **无** | ⚠⚠ **两条线都没有** |
| ⑦ 门控间冗余（G4） | 不适用 | `gate_g4_clusters.py`（独立工具） | ⚠ **未接入统一流水线**（已核实） |

### 2.2 关键发现

1. **`value_fingerprint` 已在门控线实现并接线**（`gate_search_prepare_f1` 的 `reject_vfp`），
   **不是缺失** —— 但它对行业门控**退化为无效判据**（§3.2）。
2. **`family_fp` 的粒度只到"同基础量"**：`sha1(level|base)` ⇒
   `GM_amp_med_level` 与 `GM_amp_med_chg` 同 `family_fp`（同族），
   但**不同基础量的候选不会被这一层拦住**（如 `GM_amp_med_*` vs `GM_xs_iqr_*`）。
3. **效应相似层（ΔIC 向量）两条线都没有** —— 这是唯一能回答"条件效应是否重复"的层，也是本次诊断的争议焦点。
4. **G4 未接入流水线**（已在前次审计确认）。

## 3. 任务三：冗余诊断（五层，含三次仪器陷阱）

### 3.1 L1 定义层 —— 无重复

54 规格全部唯一（§1.1）。**但粒度不含窗口/分位窗**（§1.1 注）。

### 3.2 L2a 取值层 —— `value_fingerprint` 对行业门控退化【仪器陷阱 1】

**初测（错误对象：按日期均值压平）**：

```
[market] n=40  唯一值指纹=40  ✓ 无重复
[sector] n=14  唯一值指纹=3   ⚠ 12 个门控共享同一指纹 81a2cd496561
```

**该结果无效。** 原因：行业门控的 p 是**逐日跨行业百分位排名**：

```
展平对象 (date×sector, gate) = (188116, 14)
每列 std = 0.2887 = 1/√12  ← 恰好是 [0,1] 均匀分布的标准差
uniq = 131（= 行业数）或 258/384
```

⇒ 按日期均值压平后序列**恒定**（截面 rank 的日均值天然不变），
`value_fingerprint` 测的是**边际分布**，而 rank 归一化让所有门控的边际分布相同 ⇒ **假重复**。

**这与本项目 2026-10-11 第一次 G4 实现的错误是同一类**（把 `(date,sector)` 按日期压平 → std=0 → 假"13 簇"）。
**⇒ 教训：门控线的任何诊断工具必须先验证输入对象的结构（维度、非 NaN 率、uniq、std），否则会输出"看起来正常"的假结论。**

**修正后（展平对象）**：`value_fingerprint` 仍给 2 个指纹（10 + 4），
**仍不可用于行业门控** —— 因为边际分布相同是 rank 归一化的**设计后果**，不是冗余。

### 3.3 L2b 激活层 —— 无完全重复，Jaccard 中低

**market（展平 = 逐日）**：`on = (p >= 0.7)`

```
on 日数中位 = 398 / 1050
on 模式完全相同的对 = 0
Jaccard 最高 6 对：
  0.759  GM_amp_med_ratio   GM_xs_iqr_ratio
  0.666  GM_amp_med_level   GM_xs_iqr_level
  0.606  GM_vol_med_ratio   GM_xs_iqr_ratio
  0.557  GM_sec_disp_ratio  GM_xs_iqr_ratio
  0.556  GM_vol_med_level   GM_xs_iqr_level
  0.555  GM_amp_med_ratio   GM_vol_med_ratio
```

**sector（展平 = (date,sector) 单元）**：

```
on 单元数中位 = 56992 / 188116
on 模式完全相同的对 = 0
Jaccard 最高：0.561 (amt_share_chg_level, turn_chg_chg), 0.551 (turn_chg_level, turn_chg_ratio)
```

**⇒ 激活层不冗余**（无完全重复；最高 Jaccard 0.76 意味着仍有 24% 的日数不同）。

### 3.4 L2c 结构驱动层 —— 无共同代理

逐门控 p 与结构性量的 Spearman（行业，n=14）：

| 结构量 | \|ρ\| 中位 | max |
|---|---|---|
| 同日行业收益 | 0.012 | 0.156 |
| 过去 20 日行业收益 | **0.230** | 0.591 (`GS_sec_ret_xrank_level`) |
| 行业成员数 | 0.017 | 0.425 (`GS_sec_xs_disp_level`) |

**⇒ 不存在"所有门控都是同一结构量的代理"**（只有 1 个门控 ρ>0.5）。

### 3.5 L3 效应向量层 —— 三种口径给出三个不同答案【仪器陷阱 2、3】

**对象**：`f1_market_bothdir_t.csv`，`s=+1` 口径，36 门控 × 20 因子 ΔIC 矩阵（100% 非 NaN）。

| 口径 | 中位 \|ρ\| | \|ρ\|≥0.8 对 | 单链簇数 @0.8 / @0.5 |
|---|---|---|---|
| **A 原始 ΔIC 向量** | 0.504 | **132/630** | **10 / 1** |
| B 白化 保留 99% 方差 (r=6) | 0.310 | 28/630 | — |
| B 白化 保留 95% 方差 (r=3) | 0.690 | **246/630** | — |
| C 岭白化 λ=0.1 | 0.244 | 5/630 | — |
| C 岭白化 λ=0.3 | 0.369 | 32/630 | — |
| **D 完全白化 (r=20)** | **−0.038** | **0/630** | **36 / 35** |
| 参考：G4 series（时序 p 序列） | 0.064 | 2/630 | 34 |

**为何 A 不能直接读作"冗余"**：

```
因子维度自身共线：因子间 |ρ| 中位 = 0.825，107/190 对 >= 0.8，max 0.999
效应矩阵 PCA：PC1 = 84.4%，PC1-3 = 97.1%
```

⇒ **效应向量的高相关，大部分来自"20 个因子彼此高度共线"，不是门控冗余。**

**为何 D 也不能直接读作"不冗余"**：

```
奇异谱 S：2.645e-01 ... 1.901e-04
条件数 = 1391.8   S_min/S_max = 0.0007
```

⇒ 完全白化 = 除以极小奇异值 = **放大噪声方向**。
**结论随正则化从 0/630 翻到 246/630（B 口径 r=3 vs r=20）** ⇒ **白化结果不稳健，不可作为判据。**

### 3.6 直查最高对 —— 至少 1 对真实近克隆

对原始 ρ 最高的 3 对，检查 ΔIC 向量的**比值 y/x 是否稳定**（稳定 ⇒ 成比例 ⇒ 同一效应）：

| 对 | ρ | 比值 y/x 中位 | 比值 IQR | 判定 |
|---|---|---|---|---|
| `GM_sec_disp_level` vs `GM_xs_iqr_level` | +0.982 | 0.52 | **[0.46, 0.62]** | ✅ **成比例 → 真实近克隆** |
| `GM_amt_hhi_level` vs `GM_xs_disp_ratio` | +0.984 | 0.85 | [0.13, 0.97] | ❌ 比值不稳 → 相关来自少数大分量 |
| `GM_amp_med_ratio` vs `GM_xs_iqr_ratio` | +0.964 | 0.34 | [−0.37, 0.53] | ❌ 比值变号 → 非同一效应 |

**⇒ 用户直觉"部分成立"**：`GM_sec_disp_level` / `GM_xs_iqr_level` 是真实近克隆
（跨行业离散度 vs 截面 IQR —— 两者都是"离散度"量，且都是 `level` 操作化）。
**但"54 个候选都是同一个东西的不同表达"不成立** —— 其余高 ρ 对**不成比例**。

### 3.7 诊断层小结

| 层 | 判据 | 结论 | 可信度 |
|---|---|---|---|
| L1 定义 | spec 唯一性 | 无重复 | 高（但粒度不含窗口） |
| L2a 取值 | `value_fingerprint` | **判据对 sector 退化** | ⚠ 不可用 |
| L2b 激活 | on/off Jaccard | 无完全重复，最高 0.76 | 高 |
| L2c 结构 | 与结构量相关 | 无共同代理 | 高 |
| L3 效应（A） | ΔIC 向量相关 | 132/630 ≥0.8 | ⚠ 被因子共线污染 |
| L3 效应（D） | 白化后相关 | 0/630 | ⚠ 不稳健 |
| L3 效应（直查） | 比值稳定性 | **1 对真实近克隆** | **高** |
| G4 series | 时序相关 | 34 簇 | ⚠ 口径未裁决 |

## 4. 任务四：最小修复方案（**不改代码，待批准**）

### 4.1 根因

**不是"搜索空间冗余"，而是"缺少预先规定且经验证的冗余判据"**：

1. 门控线的 `value_fingerprint` 判据**对 rank 归一化序列无效**（§3.2）——**已接线但不起作用**；
2. `family_fp` 粒度只到"同基础量"，**跨基础量的近克隆漏网**（§2.2）；
3. **效应相似层两条线都缺**，而现有候选判据（相关系数）**被因子共线污染**（§3.5）；
4. G4 口径（series vs cross）**未裁决**，且**未接入流水线**。

### 4.2 修复原则（按 Codex 要求）

- **优先确定性去重 + 值等价 + 近克隆检查**（生成时/评估前），**不做结果导向的效果筛选**；
- **不得**用 PCA 结果删候选，**不得**改 FDR 分母；
- 任何**基于结果**的效果相似性筛选必须**明确声明**：用哪些数据、在哪个阶段、对统计选择偏差的影响。

### 4.3 建议的最小改动（分三档，逐档可独立批准）

#### 档 1：修判据（零算力，无副作用）—— **建议优先**

| # | 位置 | 改动 | 理由 |
|---|---|---|---|
| 1.1 | `gate_search_space.generate_space()` 或 `gate_ledger.family_fp` | 新增 `op_family_fp = sha1(level\|base\|op)`，与 `family_fp` 并存 | 现 `family_fp` 只到基础量，操作化维度无指纹 |
| 1.2 | `gate_search_prepare_f1.py` 的 `reject_vfp` | **对 rank 归一化序列禁用 vfp 判据**（或改用 rank 不变量：逐日截面排序的一致率） | 现判据对 sector 退化（§3.2） |
| 1.3 | 新增 `gate_value_equiv.py`（只读诊断工具） | 逐日截面排序一致率 + 比值稳定性检验 | 提供**可解释**的判据，替代被污染的相关系数 |
| 1.4 | 所有诊断工具入口 | 强制"输入结构自检"（维度/非 NaN 率/uniq/std），不通过则拒绝输出 | **防 G4 v1 与 §3.2 两次同类错误重演** |

#### 档 2：接 G4 + 口径裁决（低算力）—— **需先裁决口径**

| # | 位置 | 改动 |
|---|---|---|
| 2.1 | PLAN §8.2 / §8.4 | **裁决 G4 统计对象**：series（时序共动）还是 cross（截面共动） |
| 2.2 | `run_gate_pipeline.py` S6 | 接入 G4，输出**候选集变化报告**（删了哪些、为什么） |
| 2.3 | `gate_g4_clusters.py` | 增加 `--effect-basis` 口径（ΔIC 向量）+ **正则化预声明**（禁未声明白化） |

#### 档 3：生成时多样性约束（中等算力）—— **仅在档 1 判定确有重复后**

| # | 改动 |
|---|---|
| 3.1 | 生成时拒绝"与已有候选的逐日截面排序一致率 > 阈值"的新候选 |
| 3.2 | 阈值**预先规定并验证**（不得事后挑） |
| 3.3 | 明确记录：此筛选发生在评估前，**不使用结果数据** ⇒ 不影响选择偏差 |

### 4.4 最小测试方案

| 测试 | 内容 | 期望 |
|---|---|---|
| T1 | `gate_value_equiv.py` 合成夹具：已知成比例对 / 已知独立对 / rank 归一化对 | 3/3 正确分类 |
| T2 | 输入结构自检：喂入按日期压平的 sector 面板 | **拒绝**输出（防 §3.2 复现） |
| T3 | `op_family_fp` 唯一性：54 规格 | 54 唯一 |
| T4 | G4 双口径对同一夹具 | 输出**不同**结果（证明口径确有区别） |
| T5 | 真实数据回归：`GM_sec_disp_level` vs `GM_xs_iqr_level` | 判为近克隆；其余高 ρ 对判为否 |

## 5. 任务五：可执行结论与待批准

### 5.1 直接回答用户的问题

> "看上去在搜索其实搜出来是同一个东西的不同表达，那就改这里不就完了吗？"

**部分对，但不能直接改**：

1. **确有 1 对真实近克隆**（`GM_sec_disp_level` / `GM_xs_iqr_level`，比值稳定在 [0.46,0.62]）；
2. **但"大面积重复"是仪器假象**：原始效应向量的 132/630 高相关，
   **84% 来自 20 个因子自身共线**（因子间中位 |ρ|=0.825），不是门控冗余；
3. **而"完全不重复"的结论也不可靠**：白化条件数 1391，结论随正则化从 0/630 翻到 246/630；
4. **⇒ 真正该先改的不是搜索空间，而是"冗余判据"本身** ——
   判据不预先规定并验证，改搜索空间只是把仪器噪声写进设计。

### 5.2 与 G4 口径裁决的联动（重要）

本次诊断**给 G4 口径问题提供了新证据**：

- G4 series（时序 p 相关）中位 0.064 / 34 簇；
- 效应向量口径**三种读数**（0.504 / 0.690 / −0.038）**取决于正则化**，**不可作为判据**；
- **⇒ G4 的 series 口径至少在"稳定"这一维度上优于未预声明的效应口径**；
  但它回答的是"时序共动"，**不是"条件效应是否重复"**。

**⇒ 口径裁决必须包含"判据的稳健性要求"**（预先声明正则化/退化处理），不能只选口径。

### 5.3 待批准清单

| 档 | 内容 | 算力 | 建议 |
|---|---|---|---|
| **1** | 修判据（`op_family_fp` / 禁用退化 vfp / `gate_value_equiv.py` / 输入自检） | 零 | **批准** |
| **2** | G4 口径裁决 + 接入 S6 + `--effect-basis` | 低 | **批准**（先裁决口径） |
| **3** | 生成时多样性约束 | 中 | **暂缓**（等档 1 判定） |

**不做**：不做 15 条机制登记表（支线）、不做追溯性预注册、不做层次 FDR、
**不按 PCA 删候选**、**不改 FDR 分母**。

### 5.4 结论

> **当前没有证据支持"搜索空间大面积冗余"；有证据支持"至少 1 对真实近克隆"；
> 有强证据支持"项目缺少预先规定且经验证的冗余判据"。**
>
> **最小修复 = 先修判据（档 1），再裁决 G4 口径（档 2），最后才考虑生成时约束（档 3）。**

## 6. 公式与原始取值的逐层核查

### 6.1 基础量定义（10 个市场基础量，raw 序列 Spearman，n=1436 日）

| base_A | base_B | Spearman |
|---|---|---|
| amp_med | xs_iqr | **+0.898** |
| amp_med | vol_med | +0.849 |
| sec_disp | xs_iqr | +0.841 |
| vol_med | xs_iqr | +0.798 |
| sec_disp | xs_disp | +0.792 |
| xs_disp | xs_iqr | +0.712 |

**|ρ|≥0.9 对 = 0；≥0.8 对 = 3；≥0.7 对 = 7（共 45 对）。**

**⇒ 基础量定义不重叠**：最高 +0.898 未达"同一量的缩放"标准（需 ρ≈1）。

**推翻一个假设**：我曾推断 `xs_disp`（全市场 pct_chg 的 std）与 `xs_iqr`
（**同一分布**的 P75−P25）是"同一分布的不同统计量" ⇒ 应高度重复。
**实测仅 ρ=+0.519** —— 同一分布上 std 与 IQR 的时序相关很低（尾部/中部驱动不同）。

### 6.2 操作化维度（同一基础量的 4 个 op，raw 序列）

| op 对 | |ρ| 中位（跨 10 基础量） | 范围 |
|---|---|---|---|
| level–chg | +0.059 | [0.017, 0.141] |
| **level–ratio** | **+0.761** | [0.020, 0.892] |
| level–accel | −0.121 | [−0.392, −0.068] |
| chg–ratio | +0.139 | [0.023, 0.216] |
| chg–accel | −0.005 | [−0.045, 0.000] |
| ratio–accel | −0.143 | [−0.424, 0.026] |

**6 个 op 对的 |ρ| 中位 = 0.114。**

**⇒ 操作化不冗余。** 唯一部分重叠：`level` vs `ratio`（同基础量，中位 0.761，
最高 `newhigh_ratio` 0.892）—— 因为 `ratio = mean20/mean120` 与 `level = mean20`
**共享分子**。但 0.892 ≠ 1，**不构成"同一量的缩放"**，不删。

### 6.3 门控实际状态（p 序列）—— **决定性层**

| 对象 | 对数 | 中位 \|ρ\| | p90 | ≥0.8 对 |
|---|---|---|---|---|
| raw（未归一化） | 780 | 0.065 | 0.407 | 7（1%） |
| **p（滚动 252 分位）** | 780 | **0.066** | 0.356 | **3（0%）** |

**⇒ 归一化（滚动分位）不是放大器；40 个市场门控的 p 序列基本不相关。**

### 6.4 效应向量为何"看起来冗余"（回收 §3.5 的争议）

```
归一化后余弦（门控两两）：中位 0.4888  min −0.9888  ≥0.9 对 = 100/630
与「全体门控平均效应向量」的相关：中位 +0.703  |r|≥0.9 = 12/36
逐因子 CV = std/|mean| 中位 = 2.057
```

**⇒ 效应向量**部分**单维（12/36 与共同方向 |r|≥0.9），但**不是全同向**
（余弦中位 0.49，且有 min −0.99 的反向对）。
**§3.5 的"132/630 ≥0.8"因此**不能**读作门控冗余：它与 §3.6 的"比值不稳"
（`GM_amt_hhi_level`/`GM_xs_disp_ratio` IQR [0.13,0.97]、`GM_amp_med_ratio`/
`GM_xs_iqr_ratio` IQR [−0.37,0.53]）一致指向"共同分量驱动"，而非等价。**

**⇒ §3.6 我判定的"至少 1 对真实近克隆"（`GM_sec_disp_level` vs `GM_xs_iqr_level`，
比值稳定 [0.46,0.62]）也需撤回为"未定"**：既然多数门控的效应向量都近似成比例，
"比值稳定"在该口径下**不是等价证据**。**该对在 6.1/6.2/6.3 三层均无重复证据**
（`sec_disp` vs `xs_iqr` raw ρ=0.841；两者 op=level，op 层不适用）。
