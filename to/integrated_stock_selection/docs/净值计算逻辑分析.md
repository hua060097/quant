# 净值计算逻辑分析与修复方案

## 当前问题

当前代码只在股票**卖出时**才计算收益，而不是每日更新净值。这导致：
- portfolio_values 在前N天一直为 1.0
- 无法反映持仓期间的盈亏波动

## 正确的净值计算逻辑

### 应该的方式：
1. **每日收盘**计算当前持仓的价值
2. 即使股票未卖出，也要按收盘价计算浮动盈亏
3. 只有在卖出时才扣除交易成本

### 时间线示例（holding_days=3）：

```
T日   : 选股，净值=1.0
T+1日 : 开盘买入股票A（价格10元）
      收盘时A价格=10.5元，净值=1.05（浮动盈亏+5%）
T+2日 : 收盘时A价格=11元，净值=1.10（浮动盈亏+10%）
T+3日 : 收盘时A价格=10.8元，净值=1.08（扣除成本后）
      同时卖出A，买入新的股票B
T+4日 : 继续持有B...
```

## 代码修改方案

需要维护一个持仓列表，记录当前持有的股票及其买入价：

```python
# 1. 维护持仓列表
current_holdings = []  # [{'stock_code': '000001', 'buy_price': 10.0, 'buy_date': '2024-01-02', ...}]

# 2. 每日更新净值
for date_idx, date in enumerate(trading_dates):
    # 2.1 计算当前持仓的市值
    daily_portfolio_value = 0.0

    # 遍历所有持仓股票
    for holding in current_holdings:
        # 获取当日收盘价
        current_price_data = backtest_data[
            (backtest_data['stock_code'] == holding['stock_code']) &
            (backtest_data['date'] == date)
        ]

        if not current_price_data.empty:
            current_price = current_price_data.iloc[0]['close_front']
            # 计算该股票当前价值
            stock_value = current_price / holding['buy_price'] * holding['position_value']
            daily_portfolio_value += stock_value

    # 2.2 处理到期的持仓
    if date_idx >= holding_days:
        # 获取到期的持仓（T日选股的股票）
        selection_date = trading_dates[date_idx - holding_days]

        # 找到这些股票并卖出
        expired_holdings = [h for h in current_holdings if h['selection_date'] == selection_date]

        for holding in expired_holdings:
            # 计算卖出收益（扣除交易成本）
            sell_data = backtest_data[
                (backtest_data['stock_code'] == holding['stock_code']) &
                (backtest_data['date'] == date)
            ]

            if not sell_data.empty:
                sell_price = sell_data.iloc[0]['close_front']
                gross_return = (sell_price - holding['buy_price']) / holding['buy_price']
                net_return = gross_return - TRADING_COST_TOTAL

                # 更新净值
                portfolio_value = portfolio_value * (1 + net_return * holding['weight'])

                # 记录交易
                all_trades.append({
                    'buy_date': holding['buy_date'],
                    'sell_date': date,
                    'buy_price': holding['buy_price'],
                    'sell_price': sell_price,
                    'net_return': net_return,
                    ...
                })

            # 从持仓列表中移除
            current_holdings.remove(holding)

    # 2.3 记录净值
    portfolio_values.append(portfolio_value)

    # 2.4 处理新的选股（T+1日买入）
    if date_idx < len(trading_dates) - holding_days:
        selection_date = trading_dates[date_idx]
        buy_date = trading_dates[date_idx + 1]

        # T日选股，T+1日买入
        # ... 选股逻辑 ...

        # 添加到持仓列表
        for stock in selected_stocks:
            buy_data = backtest_data[
                (backtest_data['stock_code'] == stock['stock_code']) &
                (backtest_data['date'] == buy_date)
            ]

            if not buy_data.empty:
                buy_price = buy_data.iloc[0]['open_front']
                current_holdings.append({
                    'stock_code': stock['stock_code'],
                    'buy_price': buy_price,
                    'buy_date': buy_date,
                    'selection_date': selection_date,
                    'position_value': 1.0 / stock_count,  # 等权重
                    'weight': 1.0 / stock_count
                })
```

## 关键改进点

1. **每日更新净值**：基于所有持仓的当日收盘价
2. **维护持仓列表**：记录买入价格、日期、权重等信息
3. **分离浮动盈亏和已实现盈亏**：
   - 每日计算浮动盈亏（用于净值显示）
   - 卖出时计算已实现盈亏（扣除交易成本）
4. **正确的资金分配**：等权重分配资金到各只股票

## 实现细节

1. 需要在买入时记录股票的买入价格和权重
2. 每日遍历持仓列表，计算当日市值
3. 卖出时只更新该部分的净值，不影响其他持仓
4. 保持净值连续性，避免跳跃
