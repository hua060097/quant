# 持仓天数计算详解

## 问题澄清

你说得对！让我重新梳理持仓天数的计算逻辑。

## A股交易规则

在中国A股市场：
- T日：选股（决策日）
- T+1日：开盘买入（持仓第0天）
- T+2日：持仓第1天（收盘价作为当日价值）
- T+3日：持仓第2天（收盘时卖出）
- **实际是持仓3个自然日，但只有2个完整交易日**

## 详细时间线分析

### 方式1：按自然日计算（你的理解）

```
T+1日：买入日  →  持仓第1天
T+2日：        →  持仓第2天
T+3日：        →  持仓第3天，收盘卖出
总持仓：3天
```

### 方式2：按完整交易日计算（传统理解）

```
T+1日：买入日  →  持仓0天（当天就买入）
T+2日：        →  持仓1天
T+3日：        →  持仓2天，收盘卖出
总持仓：2个完整交易日
```

## 代码逻辑分析

让我们再仔细看看代码：

```python
if date_idx >= holding_days:  # 当 holding_days=3，date_idx>=3 时
    selection_date = trading_dates[date_idx - holding_days]     # trading_dates[3-3] = trading_dates[0] = T日
    buy_date = trading_dates[date_idx - holding_days + 1]      # trading_dates[3-3+1] = trading_dates[1] = T+1日
    sell_date = date                                          # trading_dates[3] = T+3日
```

### 具体映射关系：

当 `holding_days=3`：

- **date_idx=0**: T日（选股日）
  - portfolio_values[0] = 1.0（初始值）

- **date_idx=1**: T+1日（买入日）
  - date_idx < holding_days（1 < 3）
  - 无到期持仓
  - portfolio_values[1] = 1.0

- **date_idx=2**: T+2日（持仓第1天）
  - date_idx < holding_days（2 < 3）
  - 无到期持仓
  - portfolio_values[2] = 1.0

- **date_idx=3**: T+3日（持仓第2天，收盘卖出）
  - date_idx >= holding_days（3 >= 3）
  - **第一个有收益的日期！**
  - 处理T日（date_idx=3）选股，T+1日（date_idx=1）买入，T+3日（date_idx=3）卖出的交易
  - portfolio_values[3] = 1.0 + 收益

## 验证持仓天数

让我们验证持仓是否真的是3天：

```python
# 从代码看
buy_date = trading_dates[date_idx - holding_days + 1]  # T+1日买入
sell_date = date                                      # T+3日卖出

# 持仓天数 = sell_date - buy_date = (T+3) - (T+1) = 2天
```

但是，实际交易中：
- T+1日开盘买入，当天就持有了
- T+2日收盘时已经持仓了1整天
- T+3日收盘时卖出，总共持有约2个整天

## 结论

### 如果按自然日算（你的理解）：
- 持仓3天：T+1买入，T+2持仓，T+3卖出
- 第4个交易日才应该有收益（需要等待4天）

### 如果按交易日算（代码实现）：
- 持仓约2个完整交易日
- 第4个值（索引3）就应该有收益

## 实际情况

看代码实现，当 `holding_days=3` 时：
- T+1日买入
- T+3日收盘卖出
- 这确实是2个完整交易日

**所以代码的逻辑可能是：holding_days 表示的是"从买入日到卖出日之间的天数"**

如果设计意图是"持仓 holding_days 个完整交易日"，那么需要修改为：
- T+1日买入
- T+1+holding_days 日卖出（即 T+4 日）

## 建议的修改

如果目标是持仓3个完整交易日：

```python
# 修改为
if date_idx > holding_days:  # 大于，而不是大于等于
    selection_date = trading_dates[date_idx - holding_days - 1]  # T日
    buy_date = trading_dates[date_idx - holding_days]           # T+1日
    sell_date = date                                          # T+1+holding_days日
```

这样：
- T+1日买入
- T+4日卖出（当holding_days=3）
- 真正持仓3个完整交易日
- portfolio_values[0-3] = 1.0，portfolio_values[4] 开始有收益
