# 净值数据结构优化总结

## 已完成的优化

### 1. 数据含义分析

| 数据组 | 含义 | 保存必要性 | 处理方式 |
|--------|------|------------|----------|
| `portfolio_values` | 组合净值（扣除交易成本） | ✅ 必须保存 | 保留并每日更新 |
| `portfolio_values_gross` | 组合净值（未扣除成本） | ❌ 不需要保存 | 删除，可从净收益+成本反推 |
| `daily_returns` | 每日收益率 | ❌ 不需要保存 | 删除，可从净值计算 |

### 2. 数据结构优化

#### 原结构（每个stock_count）：
```json
{
  "portfolio_values": [1.0, 1.05, 1.03, ...],
  "portfolio_values_gross": [1.0, 1.052, 1.032, ...],
  "daily_returns": [0.0, 0.05, -0.019, ...],
  "dates": ["2024-01-01", "2024-01-02", ...]
}
```

#### 优化后结构：
```json
{
  "portfolio_data": {
    "top_1": {
      "dates": ["2024-01-01", "2024-01-02", "2024-01-03", ...],
      "net_values": [1.0, 1.05, 1.03, ...],
      "daily_holdings": [
        [],  // 第1天无持仓
        [     // 第2天持仓
          {
            "stock_code": "000001.SZ",
            "buy_price": 10.00,
            "current_price": 10.25,
            "return_pct": 2.50,
            "weight": 0.2
          }
        ],
        ...
      ],
      "completed_trades": [...]  // 已完成的交易记录
    },
    "top_2": { ... }
  }
}
```

### 3. 修改的关键点

#### 3.1 删除冗余数据
- 移除了 `portfolio_values_gross`
- 移除了 `daily_returns`
- 移除了重复的日期处理

#### 3.2 新增每日持仓记录
- 每日记录所有持仓股票的详细信息
- 包括：股票代码、买入价、当前价、收益率、权重

#### 3.3 优化存储格式
- 日期使用字符串格式（YYYY-MM-DD）
- 价格保留2位小数
- 收益率保留2位小数
- 权重保留4位小数

### 4. 新增的保存文件

1. **daily_selections_detail_*.json** - 详细的选股交易记录
2. **walkforward_portfolio_data_*.json** - 净值和持仓数据（新增）

### 6. 优势

1. **数据完整性**：净值、日期、持仓信息关联在一起
2. **便于分析**：可以直观看到每天的持仓变化
3. **减少冗余**：不保存可计算的数据
4. **提高效率**：文件体积更小，加载更快

### 7. 兼容性

- 保持了原有的 `backtest_results` 和 `detailed_trades` 结构
- 新增的 `portfolio_data` 不会影响现有代码
- 所有现有功能继续正常工作

## 使用说明

### 查看净值曲线：
```python
import json
with open('walkforward_portfolio_data_20251119_173630.json') as f:
    data = json.load(f)

# 获取Top-1策略的净值
dates = data['windows']['Window_1_top_1']['dates']
values = data['windows']['Window_1_top_1']['net_values']

# 查看某一天的持仓
holdings = data['windows']['Window_1_top_1']['daily_holdings'][1]  # 第2天的持仓
for holding in holdings:
    print(f"{holding['stock_code']}: {holding['current_price']} ({holding['return_pct']}%)")
```

这个优化使数据结构更加清晰，便于分析和可视化净值表现和持仓变化。
