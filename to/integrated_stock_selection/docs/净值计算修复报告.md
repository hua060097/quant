# 净值计算修复报告

## 问题描述

原来的代码只在股票卖出时计算收益，导致 `portfolio_values` 在前 N 天一直为 1.0，无法反映持仓期间的盈亏波动。

## 修复方案

### 核心改进

1. **每日计算净值**：基于当前持仓的收盘价计算浮动盈亏
2. **维护持仓列表**：记录所有买入但未卖出的股票
3. **分离浮动和已实现盈亏**：
   - 每日计算浮动盈亏（净值显示）
   - 卖出时计算已实现盈亏（扣除交易成本）

### 修改内容

#### 1. 新增持仓管理（第8807-8836行）

```python
# 维护当前持仓列表
current_holdings = []  # [{'stock_code': '', 'buy_price': 0, 'buy_date': '', ...}]

# 每日计算当前持仓的市值（基于收盘价）
for holding in current_holdings:
    current_price_data = backtest_data[
        (backtest_data['stock_code'] == holding['stock_code']) &
        (backtest_data['date'] == date)
    ]

    if not current_price_data.empty:
        current_price = current_price_data.iloc[0]['close_front']
        gross_return = (current_price - holding['buy_price']) / holding['buy_price']
        daily_portfolio_value += holding['position_value'] * (1 + gross_return)
```

#### 2. 修改卖出逻辑（第8838-8896行）

- 从持仓列表中找到到期的股票
- 计算最终收益（扣除交易成本）
- 更新净值并记录交易
- 从持仓列表中移除

#### 3. 新增买入逻辑（第8898-8932行）

- T日选股，T+1日买入
- 将新买入的股票添加到持仓列表
- 记录买入价格、日期、权重等信息

#### 4. 每日更新净值（第8934-8951行）

```python
# 记录每日净值
portfolio_values.append(daily_portfolio_value)
portfolio_values_gross.append(daily_portfolio_value_gross)
daily_returns.append(daily_return)
```

## 修复后的效果

### 时间线示例（holding_days=3）：

```
T日   : 选股，净值=1.0000
T+1日 : 开盘买入股票A（10元）
      收盘时A价格=10.5元，净值=1.0500（+5.0%）
T+2日 : 收盘时A价格=11元，净值=1.1000（+10.0%）
T+3日 : 收盘时A价格=10.8元，净值=1.0800（扣除成本后卖出）
      同时买入股票B
T+4日 : 持有B，净值=1.0800 + B的浮动盈亏
```

### 净值曲线特点：

1. **连续性**：净值每天都更新，反映持仓盈亏
2. **平滑性**：避免了只在卖出时才跳跃的问题
3. **真实性**：更贴近实际投资的净值变化

## 关键数据结构

### 持仓列表结构：

```python
{
    'stock_code': '000001.SZ',
    'buy_price': 10.0,
    'buy_date': '2024-01-02',
    'selection_date': '2024-01-01',
    'weight': 0.3333,        # 在组合中的权重
    'position_value': 0.3333  # 持仓价值
}
```

### 净值计算逻辑：

1. **每日市值** = Σ(持仓股票当日收盘价 / 买入价 × 持仓价值)
2. **每日收益** = (当日市值 - 昨日市值) / 昨日市值
3. **最终收益** = 卖出时计算（扣除交易成本）

## 注意事项

1. **数据一致性**：确保买入和卖出时使用相同的价格基准（前复权）
2. **交易成本**：只在卖出时扣除，不影响持仓期间的浮动盈亏
3. **资金分配**：采用等权重分配，每只股票占用 1/stock_count 的资金

## 验证方法

运行 Walk-Forward 后，检查：
1. `portfolio_values` 是否从第二天开始就有变化
2. 净值曲线是否平滑连续
3. 总收益率是否与之前一致（应该是相同的，只是计算方式不同）

这个修复使净值计算更加真实和连续，能够更好地反映策略的实际表现。
