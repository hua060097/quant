# 净值数据结构分析与优化

## 当前三个数组的含义

### 1. portfolio_values
- **含义**：组合净值（扣除交易成本后的净收益）
- **计算方式**：每日根据持仓收盘价计算浮动盈亏
- **初始值**：1.0
- **特点**：净值会每天变化，反映持仓的真实价值

### 2. portfolio_values_gross
- **含义**：组合净值（未扣除交易成本的毛收益）
- **计算方式**：与 portfolio_values 相同，但不扣除买卖成本
- **用途**：用于对比交易成本对收益的影响

### 3. daily_returns
- **含义**：每日收益率（净收益率）
- **计算方式**：(当日净值 - 昨日净值) / 昨日净值
- **初始值**：第一天为 0.0

## 是否需要保存所有三个数组？

### 建议：
1. **portfolio_values**：✅ 需要保存 - 主要的净值曲线
2. **daily_returns**：❌ 不需要单独保存 - 可以从 portfolio_values 计算出来
3. **portfolio_values_gross**：❌ 不需要保存 - 交易成本影响不大，可以直接在最终收益中体现

### 2. 构建每日持仓列表

```python
# 在回测循环中记录每日持仓
daily_holdings_list = []

for date_idx, date in enumerate(trading_dates):
    # 记录当日持仓
    day_holdings = []
    for holding in current_holdings:
        # 获取当日收盘价
        current_price_data = backtest_data[
            (backtest_data['stock_code'] == holding['stock_code']) &
            (backtest_data['date'] == date)
        ]

        if not current_price_data.empty:
            current_price = current_price_data.iloc[0]['close_front']
            return_pct = (current_price - holding['buy_price']) / holding['buy_price'] * 100

            day_holdings.append({
                'stock_code': holding['stock_code'],
                'buy_price': holding['buy_price'],
                'current_price': current_price,
                'return_pct': round(return_pct, 2),
                'weight': holding['weight']
            })

    daily_holdings_list.append(day_holdings)
```

## 优势

1. **数据关联性强**：日期、净值、持仓信息都在一个结构中
2. **易于分析**：可以直接看到某天的持仓情况
3. **减少冗余**：不保存可以计算的数据（如 daily_returns）
4. **便于可视化**：净值曲线和持仓变化一目了然
