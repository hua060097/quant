# 新股过滤逻辑修复：跳过太早上市的股票

## 🐛 问题描述

### 错误日志
```
[FILTER] 000597.SZ IPO日期: 19960523, 第60个交易日: 20221230
```

### 问题分析

**股票 000597.SZ** 于 1996 年上市，但交易日历可能只从 2022 年开始。当前代码会：
1. 在交易日历中找到第一个 ≥ 19960523 的日期（实际上是 2022-01-03）
2. 从这个日期开始计算第 60 个交易日（得到 2022-12-30）
3. 错误地对这只很早上市的股票进行"新股"过滤

**这是错误的！** 1996 年上市的股票不应该在 2022 年被当作"新股"来过滤。

---

## ✅ 修复方案

### 核心逻辑

在计算第 60 个交易日之前，先检查 IPO 日期是否在交易日历范围内：

- **如果 IPO 日期 < 交易日历起始日期**：说明股票上市太早，跳过新股过滤
- **如果 IPO 日期 > 交易日历结束日期**：说明股票上市太晚（未来），跳过新股过滤
- **只有 IPO 日期在交易日历范围内**：才计算第 60 个交易日并进行过滤

### 修复代码

**文件**: `main.py` 第 6310-6332 行

```python
# 计算过滤结束日期（IPO后第60个交易日）
if use_trading_days:
    # 检查IPO日期是否在交易日历范围内
    trading_start = trading_dates[0]
    trading_end = trading_dates[-1]

    if ipodate_str < trading_start:
        # IPO日期早于交易日历起始日期，说明这是很早上市的股票，跳过过滤
        logger.debug(f"[FILTER] {stock_code} IPO日期: {ipodate_str} 早于交易日历起始日期: {trading_start}，跳过新股过滤")
        continue

    if ipodate_str > trading_end:
        # IPO日期晚于交易日历结束日期，这种情况也应该跳过
        logger.debug(f"[FILTER] {stock_code} IPO日期: {ipodate_str} 晚于交易日历结束日期: {trading_end}，跳过新股过滤")
        continue

    # 使用交易日历计算第60个交易日
    filter_end_date = _get_nth_trading_date(ipodate_str, trading_dates, n=60, logger=logger)
    logger.info(f"[FILTER] {stock_code} IPO日期: {ipodate_str}, 第60个交易日: {filter_end_date.strftime('%Y%m%d')}")
else:
    # 降级方案：使用自然日
    filter_end_date = ipodate_dt + pd.Timedelta(days=60)
    logger.info(f"[FILTER] {stock_code} IPO日期: {ipodate_str}, 使用自然日+60: {filter_end_date.strftime('%Y%m%d')}")
```
