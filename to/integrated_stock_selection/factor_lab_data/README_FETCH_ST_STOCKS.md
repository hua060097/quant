# ST股票数据获取工具使用说明

## 功能特点

✅ **支持指定日期范围**获取ST股票列表
✅ **支持增量更新**：自动检测已有数据，避免重复获取
✅ **智能覆盖**：如果日期范围有重合，用新数据覆盖旧数据
✅ **自动限流**：遵守Tushare API的调用频率限制
✅ **错误处理**：记录成功、跳过、失败的日期
✅ **Parquet格式**：高效存储，便于后续分析

---

## 使用方法

### 基本用法

```bash
# 进入目录
cd C:\Users\86151\.trae-cn\pythons\path\to\integrated_stock_selection\factor_lab_data

# 获取指定日期范围的数据
python fetch_st_stocks.py 20240101 20240131

# 不带参数：使用默认日期（20240101~20240131）
python fetch_st_stocks.py
```

### 参数说明

- `start_date`: 开始日期，格式：YYYYMMDD（如 20240101）
- `end_date`: 结束日期，格式：YYYYMMDD（如 20240131）

### 日期处理规则

- ✅ 自动跳过周末（只获取周一到周五的数据）
- ✅ 如果某天无ST股票，会记录为"跳过"
- ✅ API调用失败会记录错误，但不影响其他日期的获取

## 增量更新功能

### 首次获取

```bash
python fetch_st_stocks.py 20240101 20240115
# 获取 20240101~20240115 的数据
# 保存到: to/local_data/st.parquet
```

### 增量追加

```bash
python fetch_st_stocks.py 20240116 20240131
# 检测到已有数据（20240101~20240115）
# 只获取新数据（20240116~20240131）
# 合并保存
```

### 覆盖更新

```bash
python fetch_st_stocks.py 20240110 20240120
# 检测到已有数据
# 识别重合日期（20240110~20240115）
# 删除旧数据，获取新数据（20240110~20240120）
# 合并保存
```

## 输出数据格式

### 文件信息

- **文件路径**: `to/local_data/st.parquet`
- **文件格式**: Parquet（列式存储，高效压缩）
- **编码**: UTF-8

### 数据结构

| 列名 | 说明 | 示例 |
|------|------|------|
| `trade_date` | 交易日期 | 20240115 |
| `ts_code` | 股票代码 | 000001.SZ |
| `name` | 股票名称 | ST平安 |
| `start_date` | ST起始日期 | 20231201 |
| `end_date` | ST结束日期（可能为空） | 20240130 |

### 示例数据

```
trade_date  ts_code    name        start_date  end_date
20240115    000001.SZ  ST平安      20231201    20240130
20240115    000002.SZ  ST万科      20231205    null
20240116    000001.SZ  ST平安      20231201    20240130
```

## 性能说明

### API限流

- Tushare API限制：每秒最多3次请求
- 脚本自动遵守：每次请求间隔 0.35 秒
- 获取100天数据大约需要：35秒

### 数据量估算

- 平均每天ST股票：100~150只
- 每条记录大小：约 100 bytes
- 1年（约250个交易日）数据：约 2.5 MB

## 错误处理

### 常见错误

#### 1. 日期格式错误

```bash
python fetch_st_stocks.py 2024-01-01 2024-01-31
# 错误: 请使用格式: YYYYMMDD

# 正确
python fetch_st_stocks.py 20240101 20240131
```

#### 2. 开始日期晚于结束日期

```bash
python fetch_st_stocks.py 20240131 20240101
# 错误: 开始日期(20240131) 不能晚于结束日期(20240101)
```

#### 3. API调用失败

```
[ERROR] 获取 20240115 失败: 接口超时
# 不影响其他日期，继续获取
```

#### 4. Token失效

```
[ERROR] 您的访问频率过高，请稍后再试
# 解决方案：
# 1. 等待几分钟后再试
# 2. 检查Tushare账户积分
# 3. 升级Tushare账户权限
```

## 读取数据示例

### Python 读取

```python
import pandas as pd

# 读取数据
df = pd.read_parquet('to/local_data/st.parquet')

# 查看基本信息
print(f"总记录数: {len(df)}")
print(f"日期范围: {df['trade_date'].min()} ~ {df['trade_date'].max()}")

# 查看某天的ST股票
st_stocks_20240115 = df[df['trade_date'] == '20240115']
print(f"20240115的ST股票: {len(st_stocks_20240115)} 只")

# 查看某只股票的ST状态
stock_000001 = df[df['ts_code'] == '000001.SZ']
print(stock_000001)
```
