# 板块-个股一体化选股系统

## 系统概述

本系统是一个基于2020-2025年顶尖量化研究的专业选股系统，实现了"板块→个股"的层次化选股策略。系统结合先进的板块潜力分析、多因子评分模型和风险控制机制，为量化交易提供高质量的股票选择。

## 核心特色

### 🎯 **智能板块分析**
- 使用`UltimateMultiDayAnalyzer`进行板块潜力分析
- 8维度板块评分体系（技术面、资金面、情绪面、相对强度等）
- Top-N筛选机制，避免过度分散
- 动态阈值调整，适应市场环境

### 🧠 **多因子评分系统**
- **技术面评分**：基于动量、趋势、技术指标一致性
- **基本面评分**：市值因子、流动性因子、质量因子
- **板块面评分**：板块强度、相似性评分、连板效应
- **资金流评分**：成交量因子、Amihud流动性、价量关系

### 🔧 **智能特征工程**
- 自动计算缺失特征（高波动率、趋势一致性、布林带位置等）
- 基于学术研究的特征设计（Fama-French、Amihud等）
- 向量化计算，高性能处理

### 📊 **多模式运行**
- **板块策略回测**：验证板块分析效果
- **训练集选股**：模型训练和验证
- **测试集选股**：最终效果评估
- **完整流程**：端到端系统运行

## 技术架构

### 数据层
- **时间范围**：2023-01-01 至 2025-03-28
- **个股特征**：105个量化特征
- **板块特征**：141个板块特征
- **目标变量**：future_return_1d（T+1到T+2收益率）
- **交易逻辑**：T+1开盘买入，T+2开盘卖出

### 算法层
- **板块分析**：UltimateMultiDayAnalyzer
- **特征计算**：FeatureCalculator
- **多因子评分**：MultiFactorScorer
- **选股引擎**：StockSelector
- **回测引擎**：Backtester

## 使用方法

### 基础使用

```bash
cd to/integrated_stock_selection

# 运行完整流程（默认）
python main.py

# 或指定完整流程模式
python main.py --mode full_pipeline
```

### 高级使用

```bash
# 仅运行板块策略回测
python main.py --mode sector_backtest

# 仅运行训练集选股（含统计分析）
python main.py --mode train_selection

# 仅运行测试集选股
python main.py --mode test_selection

# 自定义输出目录
python main.py --mode train_selection --output_dir ./custom_results

# 调整日志级别
python main.py --mode full_pipeline --log_level DEBUG
```

### 命令行参数说明

| 参数 | 选项 | 默认值 | 说明 |
|------|------|--------|------|
| `--mode` | `sector_backtest`, `train_selection`, `test_selection`, `full_pipeline` | `full_pipeline` | 运行模式 |
| `--output_dir` | 任意路径 | `./results` | 输出目录 |
| `--log_level` | `DEBUG`, `INFO`, `WARNING`, `ERROR` | `INFO` | 日志级别 |
| `--save_results` | - | `True` | 是否保存结果 |

## 运行模式详解

### 1. 板块策略回测模式 (`sector_backtest`)
- **功能**：验证板块分析算法的有效性
- **输出**：板块回测报告
- **用途**：算法验证和参数调优

### 2. 训练集选股模式 (`train_selection`)
- **功能**：在训练集上进行选股并统计分析
- **输出**：选股结果 + 详细统计报告
- **包含指标**：胜率、总收益、最大回撤、夏普比率等
- **用途**：模型训练和策略验证

### 3. 测试集选股模式 (`test_selection`)
- **功能**：在测试集上进行最终评估
- **输出**：选股结果 + 回测报告
- **用途**：策略最终验证

### 4. 完整流程模式 (`full_pipeline`)
- **功能**：运行完整的选股和回测流程
- **输出**：完整的系统报告
- **用途**：生产环境使用

## 核心性能指标

### 选股指标
- **日均选股数量**：2只股票
- **板块筛选数量**：前5个优质板块
- **特征维度**：105个个股特征 + 141个板块特征
- **评分维度**：技术面、基本面、板块面、资金流面

### 回测指标
- **胜率**：选中股票盈利的比例
- **总收益率**：累计收益率
- **年化收益率**：年化后的收益率
- **最大回撤**：最大亏损幅度
- **夏普比率**：风险调整后收益
- **卡尔马比率**：收益回撤比
- **波动率**：收益率标准差

### 风险控制
- **最小市值**：50亿元
- **最小成交额**：5000万元
- **最大波动率**：15%
- **ST股票过滤**：自动排除
- **跌停股票过滤**：自动排除

- **Python版本**：3.8+

- **存储空间**：建议10GB+（含数据缓存）

## 注意事项

1. **数据完整性**：确保数据文件完整，系统会自动验证
2. **缓存管理**：首次运行会生成缓存，后续运行速度显著提升
3. **结果解读**：关注胜率和夏普比率，而非单纯的收益率
4. **风险控制**：系统已内置多重风险控制，但仍需结合实际情况
5. **参数调优**：可通过config.py调整系统参数
