# 机器学习K线形态选股模式使用说明

## 概述

本模式实现了基于机器学习的K线形态选股策略，通过XGBoost分类器学习特征组合，识别具有上涨潜力的股票。

## 核心特性

### 1. 特征工程增强
- **K线形态特征**: 金勺底、W底、N型、上升三角形、杯柄形态、旗形、突破形态等7种形态
- **累计涨幅特征**: 近3日、5日、10日累计涨幅
- **技术指标**: RSI、MACD、均线系统等
- **风险特征**: 高波动率、近期跌停、低质量涨停等
- **基本面特征**: 市值、流动性、质量因子等

### 2. 选股范围限定
- 仅在每日潜力板块中选股（使用8维度板块分析）
- 过滤当日涨幅超过3%的股票，避免追高
- 动态识别前5个最具潜力的板块

### 3. 机器学习模型
- **模型类型**: XGBoost分类器
- **目标变量**: 4类收益率分类
  - 大跌: < -3%
  - 小跌: -3% 到 0%
  - 小涨: 0% 到 3%
  - 大涨: > 3%
- **特征学习**: 自动学习特征组合和交互关系

### 4. 数据划分
- **训练期**: 2023-06-01 到 2024-06-01
- **测试期**: 2024-06-02 到 2025-01-22

## 使用方法

### 1. 基本运行
```bash
# 运行机器学习K线形态选股
python main.py --mode ml_pattern_selection

# 保存结果到指定目录
python main.py --mode ml_pattern_selection --output_dir ./ml_results --save_results
```

### 2. 测试功能
```bash
# 运行测试脚本验证功能
python test_ml_pattern_selection.py
```

## 输出结果

### 1. 选股结果文件
- `ml_pattern_selections_YYYYMMDD_HHMMSS.json`: 详细选股记录
- 包含股票代码、日期、评分、置信度、实际收益率等信息

### 2. 分析报告
- `ml_pattern_analysis_report_YYYYMMDD_HHMMSS.txt`: 详细分析报告
- 包含核心指标、策略特色、性能评估等

### 3. 核心指标
- **胜率**: 预测正确的比例
- **总收益率**: 测试期累计收益
- **年化收益率**: 年化后的收益率
- **最大回撤**: 最大亏损幅度
- **夏普比率**: 风险调整后收益
- **卡尔马比率**: 收益回撤比

## 策略优势

### 1. 智能特征组合
- 自动学习最优特征组合
- 无需手动调整权重
- 捕捉复杂的非线性关系

### 2. 动态板块筛选
- 基于8维度分析识别潜力板块
- 适应市场轮动
- 提高选股精度

### 3. 风险控制
- 避免追高机制
- 多维度风险特征
- 置信度筛选

### 4. 可解释性
- 特征重要性分析
- 预测概率输出
- 详细的性能报告
