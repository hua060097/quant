# 市场数据缓存系统使用说明

## 概述

市场数据缓存系统是专为优化量化回测框架设计的高性能数据缓存解决方案。通过减少对xtdata API的重复调用，该系统可以显著提高回测和模型训练的速度，特别是在处理大量股票和长时间周期的回测场景下。

主要特点：

1. **多级缓存架构**：内存缓存 + 磁盘缓存，平衡速度和容量需求
2. **批量数据预加载**：在回测开始前预加载常用数据，减少回测过程中的API调用
3. **智能缓存管理**：使用LRU(最近最少使用)策略优化内存使用
4. **透明集成**：无需修改现有回测逻辑，直接集成到现有系统
5. **性能监控**：提供详细的缓存性能统计，帮助优化缓存配置

## 系统组件

缓存系统由以下主要组件构成：

1. **market_data_cache.py**：核心缓存实现，提供数据存储和检索功能
2. **cache_integration.py**：集成层，负责将缓存系统与现有回测框架连接
3. **optimize_backtest.py**：演示脚本，展示如何使用缓存系统优化回测

## 快速开始

### 基本用法

最简单的使用方式是运行优化回测脚本：

```bash
python to/optimize_backtest.py
```

脚本会提示是否进行性能比较测试。如果选择"y"，将依次执行标准回测和优化回测，并生成性能对比图表；如果选择"n"，只执行优化版本的回测。

### 在现有代码中集成缓存系统

1. 首先，导入缓存集成模块并初始化缓存系统：

```python
from to.cache_integration import get_cache_integration

# 初始化缓存系统（内存限制为4GB）
cache_integration = get_cache_integration(memory_limit_gb=4)

# 激活缓存系统
cache_integration.integrate()
```

2. 为回测引擎和量化模型添加缓存支持：

```python
from to.cache_integration import patch_backtest_engine, patch_quant_model

# 为BacktestEngine添加缓存支持
patch_backtest_engine()

# 为AdvancedQuantModel添加缓存支持
patch_quant_model()
```

3. 预加载数据（可选但推荐）：

```python
# 获取股票列表
model = AdvancedQuantModel()
stock_universe = model.get_stock_universe()

# 预加载数据
cache_integration.preload_data(
    stock_list=stock_universe,
    start_date='20240101',
    end_date='20240331',
    fields=['open', 'high', 'low', 'close', 'volume', 'amount'],
    periods=['1d']
)
```

4. 运行回测（现在所有数据调用都会自动使用缓存）：

```python
from to.run_backtest import run_backtest_with_params

engine, report = run_backtest_with_params(
    start_date='20240101',
    end_date='20240331',
    initial_capital=1000000
)
```

5. 在完成后恢复原始系统（可选）：

```python
from to.cache_integration import restore_all_patches

# 恢复所有原始方法
restore_all_patches()
```

## 参数配置

### 缓存系统配置

`get_cache_integration()` 函数接受以下参数：

- **memory_limit_gb**：内存缓存限制（GB），默认为4
- **cache_dir**：磁盘缓存目录，默认为"./data_cache"
- **enable_monitoring**：是否启用性能监控，默认为True

### 数据预加载配置

`preload_data()` 和 `parallel_preload()` 方法接受以下参数：

- **stock_list**：要预加载的股票列表
- **start_date**：开始日期，格式'YYYYMMDD'
- **end_date**：结束日期，格式'YYYYMMDD'
- **fields**：要预加载的字段列表，默认为['open', 'high', 'low', 'close', 'volume']
- **periods**：要预加载的周期列表，默认为['1d']

## 性能优化建议

1. **适当设置内存限制**：根据系统可用内存设置合理的`memory_limit_gb`值；
2. **预加载关键数据**：在回测前预加载常用的股票和字段数据；
3. **周期性清理缓存**：长时间运行时，使用`clear_cache()`方法清理旧缓存；
4. **使用并行预加载**：对于大量股票，使用`parallel_preload()`方法加速预加载；
5. **监控缓存性能**：使用`get_cache_stats()`或`_report_performance()`方法查看缓存性能指标。

## 常见问题

### Q: 缓存占用了太多磁盘空间，如何清理？

A: 使用`clear_cache()`方法清理缓存：

```python
# 清理所有缓存
cache_integration.clear_cache()

# 清理30天前的缓存
cache_integration.clear_cache(older_than_days=30)
```

### Q: 回测结果与未使用缓存时不一致？

A: 确保在每次运行前调用`restore_all_patches()`恢复原始系统，然后重新集成缓存系统。

### Q: 如何查看缓存性能指标？

A: 使用以下方法查看缓存统计：

```python
# 获取统计数据
stats = cache_integration.get_cache_stats()
print(stats)

# 或使用内置报告功能
cache_integration._report_performance()
```

### Q: 是否支持分钟级或秒级数据缓存？

A: 支持。在预加载时指定periods参数，如`periods=['1d', '1m', '5m']`。

## 系统要求

- Python 3.6+
- 依赖包：numpy, pandas, h5py, matplotlib
- 足够的磁盘空间用于缓存（推荐至少5GB）
- 足够的内存用于缓存（推荐至少8GB系统内存）
