# 板块轮动模型重构计划

## 1. 概述

根据现有代码分析和市场研究，板块轮动预测需要更系统化和层次化的方法。本重构计划旨在彻底改进现有模型，优化特征工程，构建更贴近市场实际的多目标预测框架，以提高预测准确性和实用性。

## 2. 核心理念转变

从单一预测未来收益率转变为**预测板块在市场周期和生命周期中的位置**，然后基于此开发更有针对性的交易策略。这一转变基于以下观察：

- 不同市场阶段下板块表现具有显著的周期性规律
- 板块本身有其自身的生命周期（萌芽-成长-成熟-衰退）
- 相对强弱比绝对收益率更能反映板块轮动机会

## 3. 特征重构方案

### 3.1 保留现有高价值特征
- 技术指标类特征：趋势、动量、RSI、MACD等
- 市场环境特征：市场类型、周期、趋势强度
- 龙头股相关特征：龙头股数量、涨停数量等
- 相对强度特征：相对于创业板的表现比较

### 4.1 多目标标签体系

#### 1. 生命周期阶段标签 (0-3)
```python
def generate_lifecycle_labels(df):
    # 创建生命周期标签列
    df['lifecycle_stage'] = 0  # 0=未定义
    
    # 1=萌芽期：成交量相对低，龙头股开始表现，但整体板块涨幅尚不明显
    mask_emerging = ((df['volume_ratio_5'] < 1.0) & 
                    (df['leading_stock_ratio'] > 0.3) & 
                    (df['up_ratio'] < 0.5) & 
                    (df['rsi14'] < 60))
    df.loc[mask_emerging, 'lifecycle_stage'] = 1
    
    # 2=成长期：放量上涨，龙头股表现强势，板块整体上涨
    mask_growth = ((df['volume_ratio_5'] > 1.2) & 
                  (df['momentum_10d'] > 0) & 
                  (df['leading_stock_ratio'] > 0.4) &
                  (df['limit_up_ratio'] > 0.1) &
                  (df['up_ratio'] > 0.6))
    df.loc[mask_growth, 'lifecycle_stage'] = 2
    
    # 3=成熟期：高位整理，成交量趋稳，板块分化
    mask_mature = ((df['rsi14'] > 60) & 
                  (df['volume_ratio_5'].between(0.8, 1.2)) & 
                  (df['consecutive_up_days'] < 3) &
                  (df['up_ratio'].between(0.4, 0.6)))
    df.loc[mask_mature, 'lifecycle_stage'] = 3
    
    # 4=衰退期：高位见顶下跌或放量滞涨
    mask_decline = ((df['rsi14'] > 75) & (df['momentum_5d'] < 0)) | \
                   ((df['volume_ratio_5'] > 1.5) & (df['change_percent'] < 0.5))
    df.loc[mask_decline, 'lifecycle_stage'] = 4
    
    return df
```

## 5. 模型架构设计

### 5.1 多任务学习架构

采用多任务学习框架，使模型同时学习多个相关但不同的任务：

```python
class SectorMultiTaskModel(nn.Module):
    def __init__(self, sector_input_size, market_input_size, hidden_size=64,
                 num_layers=2, dropout_rate=0.2, use_bn=True):
        super(SectorMultiTaskModel, self).__init__()
        
        # 共享特征提取层
        self.feature_extractor = FeatureExtractor(
            sector_input_size, market_input_size, hidden_size, num_layers, dropout_rate, use_bn
        )
        
        # 任务特定层
        self.lifecycle_head = nn.Linear(hidden_size, 4)  # 生命周期预测 (4分类)
        self.market_cycle_head = nn.Linear(hidden_size, 4)  # 市场周期适应性 (4分类)
        self.fund_flow_head = nn.Linear(hidden_size, 1)  # 资金流预测 (回归)
        self.relative_strength_head = nn.Linear(hidden_size, 1)  # 相对强度预测 (回归)
        
    def forward(self, sector_features, market_features):
        # 提取共享特征
        shared_features = self.feature_extractor(sector_features, market_features)
        
        # 任务特定预测
        lifecycle_logits = self.lifecycle_head(shared_features)
        market_cycle_logits = self.market_cycle_head(shared_features)
        fund_flow = torch.sigmoid(self.fund_flow_head(shared_features))
        relative_strength = torch.tanh(self.relative_strength_head(shared_features))
        
        return {
            'lifecycle': lifecycle_logits,
            'market_cycle': market_cycle_logits,
            'fund_flow': fund_flow,
            'relative_strength': relative_strength
        }
```

### 5.2 自注意力增强的序列模型

```python
class FeatureExtractor(nn.Module):
    def __init__(self, sector_input_size, market_input_size, hidden_size, num_layers, dropout_rate, use_bn):
        super(FeatureExtractor, self).__init__()
        
        # 板块特征处理
        self.sector_encoder = nn.GRU(
            input_size=sector_input_size,
            hidden_size=hidden_size,
            num_layers=num_layers,
            batch_first=True,
            dropout=dropout_rate if num_layers > 1 else 0
        )
        
        # 市场特征处理
        self.market_encoder = nn.GRU(
            input_size=market_input_size,
            hidden_size=hidden_size,
            num_layers=num_layers,
            batch_first=True,
            dropout=dropout_rate if num_layers > 1 else 0
        )
        
        # 自注意力层，用于捕捉序列内和跨序列的关系
        self.self_attention = nn.MultiheadAttention(
            embed_dim=hidden_size * 2,
            num_heads=4,
            dropout=dropout_rate
        )
        
        # 特征融合
        self.fusion = nn.Sequential(
            nn.Linear(hidden_size * 2, hidden_size),
            nn.ReLU(),
            nn.Dropout(dropout_rate)
        )
    
    def forward(self, sector_features, market_features):
        # 编码板块特征
        sector_output, _ = self.sector_encoder(sector_features)
        sector_features = sector_output[:, -1, :]  # 取最后一个时间步
        
        # 编码市场特征
        market_output, _ = self.market_encoder(market_features)
        market_features = market_output[:, -1, :]  # 取最后一个时间步
        
        # 合并特征
        combined = torch.cat([sector_features, market_features], dim=1)
        
        # 应用自注意力
        combined = combined.unsqueeze(0)  # [batch_size, seq_len=1, features]
        attn_output, _ = self.self_attention(combined, combined, combined)
        combined = attn_output.squeeze(0)  # [batch_size, features]
        
        # 特征融合
        output = self.fusion(combined)
        
        return output
```

## 6. 训练目标与损失函数

### 多任务损失函数

```python
class MultiTaskLoss(nn.Module):
    def __init__(self, task_weights=None):
        super(MultiTaskLoss, self).__init__()
        self.task_weights = task_weights or {
            'lifecycle': 1.0,
            'market_cycle': 0.8,
            'fund_flow': 1.2,
            'relative_strength': 1.5
        }
        
        # 任务特定损失函数
        self.lifecycle_loss = nn.CrossEntropyLoss()
        self.market_cycle_loss = nn.CrossEntropyLoss()
        self.fund_flow_loss = nn.MSELoss()
        self.relative_strength_loss = nn.MSELoss()
    
    def forward(self, predictions, targets):
        # 计算各任务损失
        lifecycle_loss = self.lifecycle_loss(predictions['lifecycle'], targets['lifecycle'])
        market_cycle_loss = self.market_cycle_loss(predictions['market_cycle'], targets['market_cycle'])
        fund_flow_loss = self.fund_flow_loss(predictions['fund_flow'], targets['fund_flow'])
        relative_strength_loss = self.relative_strength_loss(predictions['relative_strength'], targets['relative_strength'])
        
        # 加权综合
        total_loss = (
            self.task_weights['lifecycle'] * lifecycle_loss +
            self.task_weights['market_cycle'] * market_cycle_loss +
            self.task_weights['fund_flow'] * fund_flow_loss +
            self.task_weights['relative_strength'] * relative_strength_loss
        )
        
        # 返回总损失和各任务损失
        return {
            'total_loss': total_loss,
            'lifecycle_loss': lifecycle_loss,
            'market_cycle_loss': market_cycle_loss,
            'fund_flow_loss': fund_flow_loss,
            'relative_strength_loss': relative_strength_loss
        }
```

## 7. 模型输出与应用

模型将输出四个关键维度的预测：

1. **生命周期阶段**: 萌芽期、成长期、成熟期、衰退期
2. **市场周期适应性**: 板块在当前市场周期的表现预期
3. **资金流向强度**: 预测未来资金流入强度
4. **相对强度指数**: 相对大盘的超额收益预期

针对不同生命周期阶段的板块，应用不同的交易策略：

### 萌芽期策略
- 寻找低位有潜力的板块
- 布局龙头标的
- 设置较大止盈空间，小止损位
- 适用于趋势预判能力强的资金

### 成长期策略
- 追踪强势热点板块
- 选择高弹性标的
- 跟踪止损
- 适用于追涨策略

### 成熟期策略
- 板块内部轮动
- 低吸高抛震荡交易
- 减小仓位
- 适用于波段交易

### 衰退期策略
- 提前减仓或做空
- 逢高卖出
- 对冲头寸
- 适用于风控为主策略

#### 3. 相对位置注意力机制

改进序列中各时间点的重要性权重分配：

```python
class PositionalImportanceAttention(nn.Module):
    """根据序列中的相对位置分配注意力权重"""
    def __init__(self, seq_length, hidden_size):
        super().__init__()
        self.position_weights = nn.Parameter(torch.ones(seq_length))
        self.attention = nn.MultiheadAttention(hidden_size, num_heads=4)
    
    def forward(self, x):
        # x形状: [batch, seq_len, features]
        
        # 应用位置重要性权重
        weights = F.softmax(self.position_weights, dim=0)
        x_weighted = x * weights.unsqueeze(0).unsqueeze(-1)
        
        # 应用自注意力
        x_t = x_weighted.transpose(0, 1)  # [seq_len, batch, features]
        attended, _ = self.attention(x_t, x_t, x_t)
        
        return attended.transpose(0, 1)  # [batch, seq_len, features]
```

#### 4. 差异化特征重要性

为不同时间点的特征分配不同权重，强调最近数据的重要性：

```python
def apply_temporal_weights(features_seq):
    """应用时间权重，更近的数据权重更大"""
    seq_length = len(features_seq)
    # 指数衰减权重，最近的数据权重最高
    weights = np.exp(np.linspace(0, 1, seq_length)) / np.exp(1)
    weighted_features = []
    
    for i, features in enumerate(features_seq):
        # 为每个时间点的特征乘以对应权重
        weighted_features.append({k: v * weights[i] for k, v in features.items()})
    
    return weighted_features
```

## 问题分析

经过对现有代码的全面审查，我们发现了以下问题：

1. **特征处理冗余**：`_process_features_with_layers`函数生成了大量相似和冗余特征，如多个时间窗口的相似指标
2. **特征与序列构建不匹配**：在序列构建时可能引用了不存在于特征处理中的特征
3. **seq_length参数冗余**：多尺度特征框架中已使用固定的`scopes=(5,10,20)`参数，但代码中仍保留了额外的`seq_length`参数
4. **模型架构与多尺度特征处理不完全匹配**：虽然`TwoStageSectorRotationModel`支持多尺度特征，但处理逻辑可以更优化
5. **生命周期阶段判断基于硬编码规则**：当前通过硬编码阈值判断板块生命周期阶段，缺乏灵活性和精确性

## 改进方案

### 1. 优化特征处理

- 移除冗余特征，专注于高信息量特征
- 将特征处理逻辑与多尺度时序特征框架更紧密集成
- 确保所有引用的特征都在特征处理中生成

### 2. 改进多尺度特征处理

- 使用多头注意力机制优化不同时间尺度特征的融合
- 引入可学习的尺度重要性权重，自动学习短期/中期/长期特征的相对重要性
- 确保不同尺度特征处理的一致性

### 3. 移除冗余参数

- 删除`seq_length`参数，完全依赖`scopes`参数定义多尺度序列长度
- 更新模型元数据，用`scopes`替换`seq_length`
- 确保所有相关函数调用使用统一的参数系统

### 4. 优化模型架构

- 重构`TwoStageSectorRotationModel`，使其更精确地处理多尺度特征
- 使用独立的编码器分别处理短期/中期/长期特征
- 使用注意力机制整合不同时间尺度的信息
- 改进二阶段预测逻辑，使分类和回归任务更协调

### 5. 使用无监督学习识别板块生命周期阶段

- 用聚类方法（K-means、层次聚类、DBSCAN）代替硬编码规则判断板块生命周期
- 通过特征组合自动识别板块所处的萌芽期、成长期、成熟期或衰退期
- 建立聚类与生命周期阶段的映射关系
- 实现在线学习机制，根据新数据动态更新生命周期判断标准
