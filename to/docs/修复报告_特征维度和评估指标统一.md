# 修复报告：特征维度不匹配和评估指标逻辑统一

## 修复概述

本次修复解决了两个核心问题：
1. **特征维度不匹配问题**：SelectKBest期望150个特征，但实际输入了157个特征
2. **评估指标逻辑混乱问题**：positive_similarity等指标缺乏统一的计算逻辑

## 问题分析

### 1. 特征维度不匹配问题

**错误信息：**
```
ValueError: X has 157 features, but SelectKBest is expecting 150 features as input.
```

**根本原因：**
- 在`_batch_ml_predict`函数中，特征选择器在训练时使用了150个特征
- 但在预测时，输入的特征矩阵包含157个特征
- 缺乏特征维度验证和自动调整机制

### 2. 评估指标逻辑混乱问题

**问题表现：**
- `positive_similarity`在多个函数中被使用，但没有统一的初始化逻辑
- `_calculate_sector_similarity`函数定义了`positive_similarity`但从未被调用
- 各种评估指标（相似度、置信度、稳定性）计算分散且不一致
- 缺乏基于现代金融理论的评估体系

## 修复方案

### 1. 特征维度不匹配修复

**修复位置：** `_batch_ml_predict`函数 (第2648-2716行)

**修复内容：**
```python
# 修复：确保特征顺序和数量与训练时一致
if feature_selector is not None:
    # 获取特征选择器期望的特征数量
    expected_features = feature_selector.n_features_in_ if hasattr(feature_selector, 'n_features_in_') else len(available_features)
    
    # 如果特征数量不匹配，调整特征列表
    if len(available_features) != expected_features:
        if len(available_features) > expected_features:
            available_features = available_features[:expected_features]
        else:
            # 补充缺失的特征（用0填充）
            missing_count = expected_features - len(available_features)
            for i in range(missing_count):
                available_features.append(f'dummy_feature_{i}')
                complete_features_df[f'dummy_feature_{i}'] = 0

# 修复：添加特征维度验证
if feature_selector is not None:
    expected_input_features = feature_selector.n_features_in_
    actual_input_features = features_scaled.shape[1]
    
    if actual_input_features != expected_input_features:
        # 尝试调整特征矩阵维度
        if actual_input_features > expected_input_features:

        else:
```

### 2. 统一评估指标体系设计

**修复位置：** 新增`_calculate_unified_evaluation_metrics`函数 (第4055-4131行)

**设计理念：** 基于现代投资组合理论和量化金融理论

**核心指标：**

1. **信息比率 (Information Ratio)**
   - 衡量超额收益相对于跟踪误差的比率
   - 公式：`prediction_score / tracking_error_proxy`

2. **夏普比率代理 (Sharpe Ratio Proxy)**
   - 风险调整后收益
   - 公式：`prediction_score / risk_proxy`

3. **稳定性得分 (Stability Score)**
   - 预测一致性和可靠性
   - 公式：`similarity_score * 0.6 + confidence_score * 0.4`

4. **相似度得分 (Similarity Score)**
   - 历史模式匹配度
   - 考虑相似样本数量和基础置信度

5. **置信度得分 (Confidence Score)**
   - 预测置信水平
   - 综合考虑预测强度和样本支持

6. **综合得分 (Composite Score)**
   - 多因子加权综合评分
   - 权重：收益率35%，风险调整25%，稳定性20%，置信度20%

### 3. 排序逻辑优化

**修复位置：** `_high_performance_ranking_for_method`函数 (第4133-4223行)

**改进内容：**
- 使用统一评估指标进行专业排序
- 基于现代投资组合理论的多因子模型
- 多层次排序：最终排序得分 → 综合得分 → 信息比率 → 稳定性得分

### 4. 删除未使用函数

**删除内容：**
- `_calculate_sector_similarity`函数 (原第3090-3213行)
- 该函数定义了`positive_similarity`但从未被调用，导致评估指标逻辑混乱
