# 板块涨跌停板分析模块

## 功能概述

`SectorBoardAnalyzer`是一个用于分析板块内涨跌停股票情况的工具类，主要功能包括：

1. **连板统计**：统计板块内各连板数量的股票（首板、二板、三板...）
2. **涨停板类型识别**：识别一字板、T字板、炸板回封、放量板等各种类型的涨停
3. **跌停板类型识别**：识别一字跌停、高位跌停、放量跌停等跌停类型
4. **最高连板天数**：识别板块内的最高连板天数
5. **板块连板梯队结构**：分析板块内连板股票的梯队结构
6. **涨跌停溢价分析**：分析涨停股的溢价情况
7. **涨跌停板市值分布**：统计涨跌停板的市值分布（小、中、大市值）
8. **热度指数计算**：综合各指标计算板块热度指数

## 使用方法

### 单板块分析

```python
from to.sector_stock_analysis import SectorBoardAnalyzer
from to.data_loaders import get_stock_list_in_sector, get_daily_data

# 初始化分析器
analyzer = SectorBoardAnalyzer()

# 获取板块内股票列表
sector_code = "TGN人工智能"
stocks = get_stock_list_in_sector(sector_code)

# 获取股票数据
date = "20230515"
stock_data = get_daily_data(stocks, date, date)

# 将DataFrame转为字典格式
stock_dict = {}
for _, row in stock_data.iterrows():
    stock_code = row.get('stock_code')
    if stock_code:
        stock_dict[stock_code] = row.to_dict()

# 处理数据
result = analyzer.process_sector_data(sector_code, date, stock_dict)

# 输出涨停数据
print(f"涨停数量: {result['limit_up_count']}")
print(f"各连板数量: {result['board_counts']}")
print(f"涨停类型分布: {result['limit_up_types']}")
print(f"热度指数: {result['heat_index']}")
```

### 批量处理

```python
from to.sector_stock_analysis import SectorBoardAnalyzer
import pandas as pd

# 初始化分析器
analyzer = SectorBoardAnalyzer()

# 设置日期范围
start_date = "20230501"
end_date = "20230531"
date_range = []
current_date = pd.to_datetime(start_date)
end_date_obj = pd.to_datetime(end_date)
while current_date <= end_date_obj:
    date_range.append(current_date.strftime('%Y%m%d'))
    current_date += pd.Timedelta(days=1)

# 获取板块列表
from to.data_loaders import get_sector_list
sector_list = get_sector_list()

# 批量处理
result = analyzer.batch_process_sectors(sector_list, date_range)
```

### 命令行使用

```bash
# 单个板块单日分析
python -m to.sector_stock_analysis --mode=single --sector=TGN人工智能 --date=20230515

# 批量处理
python -m to.sector_stock_analysis --mode=batch --start_date=20230501 --end_date=20230531
```

## 输出结果说明

分析结果包含以下主要指标：

1. **基本信息**
   - `sector_code`: 板块代码
   - `date`: 分析日期
   - `stock_count`: 股票总数

2. **涨跌停统计**
   - `limit_up_count`: 涨停股票数量
   - `limit_down_count`: 跌停股票数量
   - `board_counts`: 各连板数量统计
   - `limit_up_stocks`: 涨停股票列表
   - `limit_down_stocks`: 跌停股票列表

3. **类型分析**
   - `limit_up_types`: 涨停板类型分布
   - `limit_down_types`: 跌停板类型分布

4. **市值分布**
   - `limit_up_market_cap_dist`: 涨停股票市值分布
   - `limit_down_market_cap_dist`: 跌停股票市值分布

5. **综合指标**
   - `heat_index`: 板块热度指数(0-100)
