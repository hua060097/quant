# A股板块轮动模型优化训练方案

## 一、核心业务需求

1. 数据准备与特征构建优化
1.1 批量数据加载
- 时间范围: 2023年1月至2025年最新数据
- 训练集(70%): 2023年1月至2024年中
- 验证集(10%): 2024年中至2024年9月
- 测试集(20%): 2024年9月至今(预留回测部分)

### 1.1 问题定义
板块轮动是A股市场的重要特征，主要分为两种状态：
- **有主线板块**：板块持续上涨周期达3天以上，人气龙头个股涨幅巨大，板块内个股普遍活跃
- **无主线板块**：板块快速轮动但缺乏持续性，板块内个股涨停后无法持续，热点快速切换

### 1.2 业务目标
1. **板块持续性预测**：识别具有持续性的主线板块，避免买在顶点
2. **轮动转换点把握**：捕捉从无主线到有主线板块的切换时机，抓住最佳买点
3. **多时间尺度预测**：同时预测1天、3天、5天、10天的板块表现和持续性

## 二、高级特征体系设计

### 2.1 多层次特征架构
根据已有的`_process_features_with_layers`方法，构建五层特征架构：

1. **基础层特征**（1天更新）
   - 价格数据：收盘价、开盘价、最高价、最低价、涨跌幅
   - 成交数据：成交量、成交额、换手率、振幅
   - 板块成分股统计：板块股票数量、上涨/下跌/平盘股票数量及比例

2. **技术指标层**（1天更新）
   - 趋势指标：均线系统(MA5/10/20/30/60/120)、均线多头/空头排列、均线斜率
   - 动量指标：RSI、MACD、KDJ、不同周期动量值
   - 波动指标：波动率、ATR、布林带宽度
   - 量能指标：成交量比率、量能趋势、放量/缩量特征
   - 形态特征：连续上涨/下跌天数、摆动模式、支撑阻力位置

3. **市场环境层**（1天更新）
   - 市场状态：市场类型(1-53)、市场周期、趋势强度
   - 风险指标：市场风险水平、信号强度
   - 创业板指标：趋势评分、动量评分、波动率评分等
   - 市场环境分类：牛市、熊市、震荡市的细分状态

4. **板块特有层**（周期更新）
   - 相对强度：板块相对大盘、相对行业的强弱对比
   - 季节性特征：月度、季度历史表现
   - 市场环境适应性：板块在不同市场环境下的表现特征
   - 轮动特征：板块轮动周期、持续性指标

5. **标签设计层**（预测目标）
   - 板块排名：未来1/3/5/10天板块涨幅排名
   - 持续性指标：未来连续上涨概率、最大回撤预测
   - 主线板块概率：成为市场主线板块的概率

### 2.2 板块持续性特征增强

针对板块轮动和持续性预测，需要补充以下关键特征：

1. **板块热度动量指标**
   - 龙头股连板天数：板块内股票连续涨停天数统计
   - 涨停股比例变化：连续N天的涨停数量变化率
   - 板块资金流向：主力资金净流入变化趋势
   - 龙头股强度：龙头股相对板块整体的强度指标

2. **轮动周期识别特征**
   - 板块轮动频率：多少天内出现主题切换
   - 持续性历史统计：历史上该板块持续上涨的平均天数
   - 板块共振指数：板块内股票同向变动比例
   - 热点切换信号：从其他板块向该板块的资金流转指标

3. **趋势持续性预测特征**
   - 连续突破天数：连续突破前期高点的天数
   - 量价配合度：价格上涨与成交量变化的匹配程度
   - 龙头效应指数：龙头股带动板块的能力指标
   - 技术形态识别：头肩底、双底等经典形态识别

4. **市场情绪特征**
   - 情绪热度指标：社交媒体提及频率、搜索指数
   - 融资融券变化：板块融资融券余额变化趋势
   - 主力持仓变化：机构、北向资金持仓变化
   - 市场预期指标：基于消息面的预期变化指标

## 三、多层次模型架构设计

### 3.1 三层模型架构

1. **市场环境分类模型**（第一层）
   - **输入**：大盘技术指标、宏观经济数据
   - **输出**：当前及预期市场环境分类（9种市场类型）
   - **模型**：LightGBM分类器
   - **优化**：对不同市场状态的准确识别率进行优化，特别关注市场转折点

2. **板块持续性预测模型**（第二层）
   - **输入**：板块特征、第一层预测的市场环境、板块轮动周期特征
   - **输出**：
     - 未来1/3/5/10天的预期收益率
     - 板块持续强势概率
     - 龙头股持续性预测
   - **模型**：XGBoost回归器 + 持续性分类器
   - **优化**：重点优化对板块持续性的预测准确率

3. **综合决策模型**（第三层）
   - **输入**：前两层结果 + 原始特征 + 市场情绪指标
   - **输出**：
     - 板块推荐排名
     - 持仓建议（买入/持有/卖出）
     - 预期持有时间
   - **模型**：液体神经网络(LNN)
   - **优化**：针对不同市场环境下的板块表现进行优化

### 3.2 模型训练增强策略

1. **时间序列特性增强**
   - 使用滑动窗口训练，捕捉最新市场特征
   - 对近期数据赋予更高权重，提高模型对最新市场变化的敏感度
   - 引入时序注意力机制，捕捉板块轮动的时间依赖关系

2. **板块轮动周期适应**
   - 构建板块轮动周期自适应模型
   - 针对不同板块轮动速度的市场阶段，动态调整预测策略
   - 引入市场状态转换概率矩阵，预测轮动拐点

3. **持续性特征强化**
   - 针对板块持续性特征进行特征工程
   - 构建专门的持续性预测子模型
   - 引入历史相似行情匹配算法，从历史数据中学习相似模式

4. **多目标联合优化**
   - 同时优化短期收益率预测和持续性预测
   - 使用自适应权重平衡不同时间尺度的预测准确度
   - 引入投资组合夏普比率作为模型优化目标之一
