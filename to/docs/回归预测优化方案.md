# 板块轮动回归预测优化方案

## 1. 概述

本文档描述了板块轮动预测系统从分类模型到回归模型的转换优化方案。改进后的系统能够直接预测板块的未来收益率（`future_return_2d`），而不再局限于预测板块是否会成为表现最佳的板块之一，使得预测结果更加精细和可靠。

## 2. 系统架构变更

### 2.1 从分类到回归

原有系统主要基于分类任务，预测板块是否会成为表现最佳的板块（`is_top_performer`标签）。新系统直接预测板块的未来收益率（`future_return_2d`），从而实现更精细的板块表现预测。

### 2.2 优化组件

- **增强的LNN模型**: 从原始的LiquidNetwork升级到ImprovedLiquidNeuralNetwork
- **校准机制**: 添加多种预测校准方法，提高预测精度
- **评估框架**: 更新为适合回归任务的评估指标
- **特征工程改进**: 优化特征处理流程，适应回归任务

## 3. 主要改进内容

### 3.1 模型架构优化

#### 3.1.1 ImprovedLiquidNeuralNetwork

增强版LNN模型包含以下改进：

- **批归一化和层归一化**: 稳定训练过程，加速收敛
- **Dropout正则化**: 防止过拟合，提高泛化能力
- **残差连接**: 避免深层网络的梯度消失问题
- **学习率调度器**: 自动调整学习率，优化训练过程
- **权重初始化优化**: 更好的权重初始化方法，改善训练稳定性

#### 3.1.2 损失函数变更

- 从二元交叉熵损失（`BCEWithLogitsLoss`）改为均方误差损失（`MSELoss`）
- 添加可选的Huber损失，对异常值更稳健

### 3.2 预测校准机制

新增预测校准模块（`regression_model_calibrator.py`），包含多种校准方法：

- **等回归校准**: 使用非参数化的单调映射校准预测
- **线性缩放校准**: 调整预测值的均值和标准差以匹配历史数据
- **分位数映射校准**: 通过分位数映射调整整个分布
- **集成校准**: 组合多种校准方式获得更稳健的结果

### 3.3 评估指标更新

更新评估框架，使用适合回归任务的指标：

- **MAE (平均绝对误差)**: 评估预测值与真实值的平均偏差
- **RMSE (均方根误差)**: 对大误差更敏感的评估指标
- **R² (决定系数)**: 评估模型解释方差的程度
- **方向准确率**: 评估预测收益率正负符号的准确性
- **Spearman相关系数**: 评估排序相关性，不受非线性影响
- **Pearson相关系数**: 评估线性相关性

### 3.4 特征工程优化

- **收益率序列特征**: 基于收益率的时间序列特征
- **波动性相关特征**: 捕捉收益率波动特性
- **市场状态融合**: 结合市场环境特征改善预测
- **时间权重衰减**: 增强最近数据的影响力

### 3.5 早期停止机制

实现更完善的早期停止策略：

```python
class EarlyStopping:
    def __init__(self, patience=10, min_delta=0.001, restore_best_weights=True):
        self.patience = patience
        self.min_delta = min_delta
        self.restore_best_weights = restore_best_weights
        self.best_loss = float('inf')
        self.wait = 0
        self.best_weights = None
        self.stopped_epoch = 0
        
    def __call__(self, val_loss, model=None):
        # 检查当前损失是否比最佳损失改善了min_delta
        if val_loss < self.best_loss - self.min_delta:
            self.best_loss = val_loss
            self.wait = 0
            # 保存最佳模型权重
            if self.restore_best_weights and model is not None:
                self.best_weights = model.state_dict().copy()
        else:
            self.wait += 1
            if self.wait >= self.patience:
                self.stopped_epoch = self.wait
                # 恢复最佳权重
                if self.restore_best_weights and model is not None and self.best_weights is not None:
                    model.load_state_dict(self.best_weights)
                return True  # 停止训练
        return False  # 继续训练
```

## 4. 实现流程

### 4.1 训练流程

1. 加载特征数据（使用现有的`_batch_load_features`函数，不修改）
2. 创建回归目标标签（`future_return_2d`）
3. 应用特征工程和预处理
4. 训练改进的LNN模型和其他模型
5. 创建集成模型
6. 拟合校准器

### 4.2 预测流程

1. 加载模型和校准器
2. 准备测试数据
3. 生成原始预测
4. 应用校准
5. 输出排名和收益率预测

## 5. 使用示例

使用`regression_prediction_example.py`脚本进行模型训练和回测：

```bash
python -m to.regression_prediction_example --sector_list TGN新能源汽车 TGN算力租赁 --start_date 20230101 --end_date 20230630 --use_calibration
```

参数说明：
- `--sector_list`: 指定板块列表
- `--start_date`/`--end_date`: 指定训练和回测日期范围
- `--model_name`: 指定模型名称
- `--train_only`: 仅训练模型，不进行回测
- `--backtest_only`: 仅进行回测，不训练模型
- `--use_calibration`: 启用预测校准

## 7. 未来优化方向

1. **深度学习模型改进**:
   - 探索Transformer架构捕捉更复杂的时序特征
   - 引入注意力机制关注最相关特征

2. **更多校准技术**:
   - 贝叶斯校准方法
   - 混合密度网络

3. **多目标学习**:
   - 同时预测多个时间周期的收益率
   - 联合建模收益率和波动性

4. **集成学习拓展**:
   - 添加更多异质基模型
   - 实现堆叠泛化(Stacking)策略

## 8. 总结

从分类到回归的转变使板块轮动预测系统能够提供更精细和可靠的预测结果。通过引入增强的LNN模型、预测校准机制和优化的评估框架，系统性能得到显著提升。这些改进使得投资决策有了更科学的依据，降低了投资风险。
