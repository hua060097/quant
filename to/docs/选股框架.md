# 基于变化点检测的智能选股框架

## 1. 框架简介

基于变化点检测的智能选股框架是一种结合了时间序列分析、模式识别和相似度匹配的选股方法。该框架通过检测股票价格和技术指标的关键变化点，分析这些变化点前后的市场表现模式，并通过相似度匹配找出当前市场中最有可能产生良好收益的股票。

### 1.1 核心思想

- **变化点检测**：识别股票价格和技术指标序列中的关键转折点
- **模式识别**：分析变化点前后的市场表现特征
- **相似度匹配**：将当前市场状态与历史模式进行匹配，预测未来表现
- **多维度特征**：结合个股特征、板块特征、相对特征和市场状态进行综合分析
- **自适应权重**：根据特征贡献度动态调整相似度计算中的特征权重
- **实时评估**：评估选出股票的实际表现，验证预测准确性

### 1.2 技术特点

- 使用先进的变化点检测算法（PELT、Binseg等）识别关键转折点
- 融合板块轮动模型，考虑个股在板块中的相对表现
- 动态权重调整，根据不同市场环境自适应调整特征权重
- 多层次特征体系，从微观到宏观全方位分析
- 特征贡献度分析，识别对预测结果影响最大的关键特征
- 预测表现评估，通过实际收益验证模型有效性

## 2. 框架结构

### 2.1 数据层

- **个股特征**：价格、成交量、技术指标等基础数据
- **板块特征**：板块整体表现、内部分化程度、龙头股表现等
- **市场状态**：大盘趋势、资金流向、风险偏好等宏观因素
- **相对特征**：个股相对于所属板块的超额表现
- **涨跌停板结构特征**：板块涨跌停情况、连板情况、一字板占比等

### 2.2 算法层

- **特征工程**：构建多层次特征体系，包括技术指标、相对指标和组合指标
- **变化点检测**：使用多种算法检测时间序列中的关键变化点
- **模式分析**：对变化点前后的市场表现进行分类和特征提取
- **相似度计算**：计算当前市场状态与历史模式的相似度，分析特征贡献度
- **综合评分**：结合预期收益率、概率和置信度进行综合评分
- **表现评估**：评估选出股票的实际表现，计算方向准确率和胜率

### 2.3 应用层

- **选股策略**：根据综合评分选择最具潜力的股票
- **风险控制**：通过多维度分析降低选股风险
- **动态调整**：根据市场变化动态调整选股策略
- **结果反馈**：通过实际表现评估反馈机制优化模型参数

## 4. 使用方法

### 4.1 命令行接口

```bash
# 运行选股功能
python train_sector_models.py --mode select_stocks --start_date 20230101 --end_date 20231231 --top_n 50 --model_name stock_selector
```

### 4.2 参数说明

- `--mode`：操作模式，选择`select_stocks`进行选股
- `--start_date`：训练数据起始日期，格式为YYYYMMDD
- `--end_date`：训练数据结束日期，格式为YYYYMMDD
- `--top_n`：选择前N只股票，默认为50
- `--model_name`：模型名称，默认为"stock_selector"

### 4.3 输出结果

选股结果将以JSON格式保存在模型目录下，包含以下内容：
- 选出的股票列表及其详细信息（股票代码、名称、预期收益率、概率、置信度等）
- 评估结果（平均实际收益率、方向准确率、胜率、表现评级等）
- 每只股票的预测准确性和实际表现情况

同时在控制台输出前20只股票的信息和评估总结。

## 5. 性能评估

### 5.1 评估指标

框架使用以下指标评估选股表现：
- **平均实际收益率**：选出股票在预测期内的平均收益率
- **方向准确率**：预测方向与实际方向一致的比例
- **胜率**：选出股票中实际收益为正的比例
- **预测准确度**：预测收益与实际收益的接近程度
- **表现评级**：根据上述指标综合评定的表现等级（优秀/良好/一般/中性/较差）

### 5.2 回测结果

该选股框架在不同市场环境下的表现评估：
- 牛市环境：超额收益X%
- 熊市环境：回撤控制在Y%以内
- 震荡市场：稳定收益Z%

### 5.3 优势分析

- 对市场转折点的敏感度高，能够及时捕捉市场机会
- 结合板块轮动，提高选股的系统性和前瞻性
- 多维度特征融合，降低单一指标带来的风险
- 自适应权重调整，适应不同市场环境
- 特征贡献度分析，提供选股逻辑解释性
- 实时评估机制，持续验证和优化模型表现

## 7. 注意事项

- 该框架需要足够的历史数据进行训练，建议至少使用1年以上的数据
- 变化点检测对数据质量敏感，请确保输入数据的准确性和完整性
- 选股结果仅供参考，实际投资决策需结合市场环境和风险偏好综合考虑
- 定期评估模型表现，根据评估结果调整模型参数和特征权重
