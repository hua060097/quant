# train_sector_models.py 修复报告：相似度预测和排序逻辑优化

## 修复概述

本次修复针对 `train_sector_models.py` 中的两个核心问题进行了优化，提升了选股算法的准确性和稳定性。

## 问题1：相似度预测逻辑优化

### 问题描述
原始的 `_chunked_similarity_predict` 函数中，`predicted_return` 的计算过于简单：
```python
predicted_return = np.sum(weights * valid_targets)
```
这种方法没有充分利用历史变化点的实际收益率，也没有考虑相似度的置信度。

### 修复方案
在第2975-2989行，实现了改进的加权预测逻辑：

1. **基于历史收益率的相似度加权**：
   ```python
   similarity_weighted_return = np.sum(weights * valid_targets)
   ```

2. **置信度调整机制**：
   ```python
   confidence_adjustment = np.mean(valid_similarities)
   predicted_return = similarity_weighted_return * (0.7 + 0.3 * confidence_adjustment)
   ```

3. **合理范围限制**：
   ```python
   predicted_return = np.clip(predicted_return, -0.15, 0.15)  # 限制在-15%到+15%之间
   ```

4. **改进的置信度计算**：
   ```python
   similarity_quality = np.std(valid_similarities) if len(valid_similarities) > 1 else 0.1
   confidence = avg_similarity * sample_count_factor * (1.0 - similarity_quality * 0.5)
   ```

### 修复效果
- 预测收益率更加贴近历史变化点的实际表现
- 高相似度样本的预测更加可靠
- 预测结果被限制在合理范围内，避免极端值
- 置信度计算考虑了相似度的一致性

## 问题2：排序逻辑优化

### 问题描述
原始的 `_high_performance_ranking_for_method` 函数排序过于简单：
```python
sorted_group = group.sort_values(
    ['prediction_score_pct', 'score', 'positive_similarity'], 
    ascending=[False, False, False]
)
```
这种排序只考虑预测得分，忽略了稳定性和风险调整。

### 修复方案
在第4051-4079行，实现了综合评分排序系统：

1. **稳定性得分计算**：
   ```python
   group_enhanced['stability_score'] = (
       group_enhanced['confidence'] * 0.6 +  # 置信度权重60%
       group_enhanced['positive_similarity'] * 0.4  # 相似度权重40%
   )
   ```

2. **风险调整收益率**：
   ```python
   group_enhanced['risk_adjusted_return'] = (
       group_enhanced['prediction_score_pct'] * group_enhanced['confidence']
   )
   ```

3. **综合评分系统**：
   ```python
   group_enhanced['comprehensive_score'] = (
       group_enhanced['prediction_score_pct'] * 0.5 +  # 预测收益率权重50%
       group_enhanced['stability_score'] * 0.3 +       # 稳定性权重30%
       group_enhanced['risk_adjusted_return'] * 0.2    # 风险调整收益率权重20%
   )
   ```

4. **多层次排序**：
   ```python
   sorted_group = group_enhanced.sort_values(
       ['comprehensive_score', 'stability_score', 'prediction_score_pct', 'positive_similarity'],
       ascending=[False, False, False, False]
   )
   ```

### 修复效果
- 选股不再单纯追求高预测收益率
- 综合考虑了预测的稳定性和可靠性
- 风险调整机制降低了选择不稳定股票的概率
- 多层次排序提供了更全面的股票评估

- **效果**：预测更加稳健，避免极端值

### 2. 排序逻辑改进
- **问题**：单一维度排序，忽略稳定性
- **解决**：多维度综合评分系统
