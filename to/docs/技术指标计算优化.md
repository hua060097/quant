## 2. 主要优化内容

### 2.1 统一返回值类型

为了解决技术指标返回类型不一致的问题，我们对所有指标计算方法进行了标准化，使它们都直接返回标量值（如float），而不是数组或Series：

```python
# 之前的方法返回整个数组
def _calculate_ma(self, data, n):
    # 计算移动平均线...
    return ma  # 返回整个ma数组

# 现在的方法直接返回最新值
def _calculate_ma(self, data, n):
    # 计算最近n个数据点的简单平均...
    return ma  # 直接返回标量值
```

这一修改应用于以下关键方法：
- `_calculate_ma` - 移动平均线计算
- `_calculate_ema` - 指数移动平均线计算
- `_calculate_rsi` - 相对强弱指数计算
- `_calculate_cci` - 商品通道指数计算

### 2.2 EMA计算方法优化

优化了指数移动平均线(EMA)的计算方法，改为直接返回最新的EMA值而不是整个EMA数组：

```python
def _calculate_ema(self, data, window):
    """
    计算给定窗口大小的指数移动平均线(EMA)
    
    Args:
        data: 价格数据的numpy数组或pandas Series
        window: EMA的窗口大小
        
    Returns:
        float: 最新的EMA值
    """
    if isinstance(data, pd.Series):
        data = data.values
        
    if len(data) < window:
        return data[-1]  # 数据不足时返回最新价格
        
    # 计算权重系数
    alpha = 2 / (window + 1)
    
    # 初始EMA为简单平均
    ema = np.mean(data[-(window*2):-(window)])
    
    # 计算EMA
    for i in range(window):
        ema = alpha * data[-(window-i)] + (1 - alpha) * ema
        
    return ema
```

### 2.3 MA计算方法优化

简化了移动平均线的计算，直接计算最近n个数据点的平均值：

```python
def _calculate_ma(self, data, n):
    """计算简单移动平均线(SMA)
    
    Args:
        data: 价格数据的numpy数组或pandas Series
        n: 周期
        
    Returns:
        float: 最新的MA值
    """
    if isinstance(data, pd.Series):
        data = data.values
        
    if len(data) < n:
        return data[-1] if len(data) > 0 else 0.0  # 数据不足时返回当前价格或0
        
    # 计算最近n个数据点的简单平均
    ma = np.mean(data[-n:])
    return ma
```

### 2.4 RSI指标计算优化

重构了RSI指标的计算逻辑，改为直接从价格变化计算，避免了潜在的问题：

```python
def _calculate_rsi(self, data, n=14):
    """计算相对强弱指数（RSI）
    
    Args:
        data: 价格数据的numpy数组或pandas Series
        n: 周期
        
    Returns:
        float: 最新的RSI值
    """
    if isinstance(data, pd.Series):
        data = data.values
        
    if len(data) <= n:
        return 50.0  # 数据不足时返回中性值
        
    # 计算价格变化
    deltas = np.diff(data[-n-1:])
    
    # 分离上涨和下跌
    gains = np.where(deltas > 0, deltas, 0)
    losses = np.where(deltas < 0, -deltas, 0)
    
    # 计算平均上涨和下跌
    avg_gain = np.mean(gains)
    avg_loss = np.mean(losses)
    
    # 计算RS和RSI
    if avg_loss == 0:
        return 100.0  # 避免除以零
    else:
        rs = avg_gain / avg_loss
        rsi = 100.0 - (100.0 / (1.0 + rs))
        
    return round(rsi, 2)
```

### 2.5 CCI指标计算优化

简化了CCI指标的计算，直接返回最新值：

```python
def _calculate_cci(self, typical_price, n=20):
    """计算商品通道指数（CCI）
    
    Args:
        typical_price: 典型价格，通常是 (high + low + close) / 3
        n: 周期
        
    Returns:
        float: 最新的CCI值
    """
    if isinstance(typical_price, pd.Series):
        typical_price = typical_price.values
        
    if len(typical_price) < n:
        return 0.0  # 数据不足时返回中性值
        
    # 计算n周期的简单移动平均
    sma = np.mean(typical_price[-n:])
    
    # 计算n周期内典型价格的平均绝对偏差
    mad = np.mean(np.abs(typical_price[-n:] - sma))
    
    # 计算CCI
    if mad > 0:
        cci = (typical_price[-1] - sma) / (0.015 * mad)
    else:
        cci = 0  # 避免除以零
        
    return round(cci, 2)
```

## 3. 问题修复

修复了特征值是Series类型而不是标量值的问题，这是导致无法正确保存特征的根本原因：

```python

# 修复后：
features['rsi6'] = rsi6  # rsi6已经是标量值
```

同时，在使用特征值时增加了类型检查和转换：

