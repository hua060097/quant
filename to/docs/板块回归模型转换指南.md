# 板块轮动量化交易系统：从分类模型到回归模型转换指南

## 概述

本文档详细说明了将板块轮动量化交易系统从分类模型（预测`is_top_performer`标签）转换为回归模型（直接预测`future_return_2d`）的全过程。转换后的系统将直接预测板块的未来收益率，而不再预测板块是否会成为表现最佳的板块。

## 已完成的修改

### 1. 目标列转换

在`train_sector_models.py`中，我们已经将目标列从`is_top_performer`改为`future_return_2d`：

```python
# 初始化变量 - 将所有必要变量在这里初始化
target_cols = ['future_return_2d']  # 直接使用未来收益率作为目标
base_cols = [col for col in train_df.columns if col not in ['date', 'sector_code', 'is_top_performer'] and not col.startswith('future_return_')]
```

### 5. LNN模型训练改进

我们已经修改了LNN模型的训练方法，使其适应回归任务：

- 将输出大小从2（分类）更改为1（回归）
- 将损失函数从`BCEWithLogitsLoss`改为`MSELoss`
- 移除了one-hot编码转换
- 将目标张量类型从`LongTensor`改为`FloatTensor`
- 更新了模型评估方法，使用MAE而非准确率

## 需要进一步修改的部分

为了完全转换系统，还需要进行以下修改：

### 1. `_predict_with_sequence` 和 `_predict_with_rolling_model`方法

这些方法可能仍然依赖于分类模型的输出格式，需要修改以适应回归模型输出。

### 2. EnsembleModel类的其他方法

需要确保`predict`和`predict_proba`方法适应回归输出。

### 3. 模型保存和加载

确保保存/加载部分正确处理回归模型的结构和参数。

### 4. LNN模型结构优化

可以考虑进一步优化LNN模型结构，使其更适合回归任务：
- 尝试不同的激活函数
- 调整学习率和正则化参数
- 添加额外的特征正则化层

### 5. 评估和回测框架

更新评估和回测框架，使用回归模型特有的指标：
- MAE（平均绝对误差）
- RMSE（均方根误差）
- R²（决定系数）
- 方向准确率（预测收益率符号的准确率）

## 结论

通过这些修改，板块轮动量化交易系统已经基本从分类模型转换为回归模型。系统现在直接预测板块的未来收益率，而不是预测板块是否会成为表现最佳的板块。这种方法允许系统捕捉更细微的收益率差异，并可能提高交易策略的整体表现。

未来可以考虑将此回归模型与其他技术指标相结合，进一步提高预测准确性，并实现更精细的资金分配策略。
