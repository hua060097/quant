# 板块轮动预测优化方案

## 1. 优化背景

原始板块轮动模型采用分类方法预测板块是否为"top performer"，存在以下问题：

1. 特征生成流程分散，缺乏统一标准
2. 预测目标简化为分类问题，降低了预测的精细度
3. 特征处理中存在启发式生成规则，影响模型稳定性
4. 训练和预测阶段特征处理不一致，可能导致特征漂移

## 2. 优化方案

我们进行了以下核心优化：

### 2.1 从分类模型转向回归模型

- **变更前**：预测板块是否为"top performer"（二分类问题）
- **变更后**：直接预测板块未来收益率（回归问题）
- **优势**：提供更精确的收益率预测，支持更精细的仓位分配和更多投资策略

### 2.2 统一特征流水线

- 创建了统一的`_apply_feature_pipeline`方法，确保训练和预测时特征生成逻辑完全一致
- 重构`FeatureProcessor.process_features`，移除启发式特征生成规则
- 在特征流水线中严格区分基础特征处理和模型级联生成的特征

### 2.3 元数据驱动的特征对齐

- 训练时记录各模型确切使用的特征列表（包括顺序）
- 预测时严格按照训练时的特征列表提取和排序特征
- 模型元数据中保存详细的特征信息，支持跨版本模型兼容

### 2.4 优化LNN特征生成

- 改进了`_ensure_lnn_features`方法，提高了特征质量检查标准
- 增加了量价行为指标作为备选特征生成方法
- 为缺失特征添加了多种高质量替代生成路径

### 2.5 完全移除分类标签- 彻底移除了`is_top_performer`分类标签相关代码- 使用`_create_return_prediction_labels`替代`_create_rolling_top_performer_labels`方法- 所有模型直接预测未来收益率(`future_return_2d`)- 代码和数据流更加简洁统一

## 3. 评估指标优化后的模型评估专注于回归指标:- **收益率预测精度**:  - MSE (均方误差)  - MAE (平均绝对误差)  - RMSE (均方根误差)  - R² (决定系数)  - 方向准确率 (正负方向预测正确率)- **投资实用性指标**:  - 预测Top5板块的平均实际收益率  - 预测Top5板块的正收益比例  - 预测值与实际收益的相关性

## 4. 预期收益

1. **预测质量提升**：直接预测收益率提供更精细的信息
2. **特征稳定性**：统一特征流水线减少特征漂移风险
3. **模型可靠性**：减少启发式规则，提高模型稳定性
4. **工程质量**：代码结构更清晰，维护性更好

## 5. 后续优化方向

1. 进一步完善特征工程，探索更多有预测力的特征
2. 尝试深度学习模型提升预测能力
3. 优化仓位分配策略，结合收益率预测和波动率预测
4. 添加风险控制模块，动态调整持仓比例
