## 1. 概述

`train_sector_models.py`是一个专门用于训练板块轮动策略模型的核心组件，通过分析多维度板块特征和市场环境因素，构建能够预测板块相对强弱和未来表现的量化模型。该组件支持单板块模型训练、多板块批量训练以及基于市场环境的自适应特征工程，为量化交易系统提供高质量的板块轮动决策支持。

## 2. 主要功能

- **板块特征工程**：构建多维度板块特征，包括价格趋势、动量、波动率、相对强度等
- **市场环境自适应**：根据不同市场类型动态调整特征生成和权重
- **多周期特征融合**：同时利用短期和长期特征，捕捉不同时间尺度的市场规律
- **模型训练与保存**：训练XGBoost和LightGBM模型并保存结果
- **特征重要性分析**：分析不同特征在预测中的贡献度
- **回测数据生成**：为策略回测提供预测数据支持
- **市场环境适应型板块选择**：根据市场状态动态调整板块选择策略

## 3. 核心类与方法

### 3.1 SectorModelTrainer类

板块模型训练器，负责特征构建、模型训练与预测。

#### 主要方法：

| 方法名 | 功能描述 |
|-------|--------|
| `_build_features_for_date_range` | 构建指定日期范围内的板块特征数据，包含时序动态特征 |
| `_prepare_training_data_enhanced` | 增强版训练数据准备，融合短期和长期特征 |
| `_add_dynamic_features` | 基于市场环境动态添加或增强特征 |
| `train_sector_model` | 训练单个板块的预测模型 |
| `train_all_sectors` | 批量训练多个板块的模型 |
| `prepare_backtest_data` | 准备回测数据，用于策略回测 |
| `_adapt_sectors_to_market` | 根据市场环境适应性选择板块 |
| `analyze_feature_importance` | 分析特征重要性，支持回测期间动态特征选择 |

## 4. 特征体系

### 4.1 核心特征类别

- **趋势特征**：MA指标、均线斜率、趋势得分
- **动量特征**：短期动量、相对动量、动量加速度
- **波动率特征**：波动率、波动率变化比率
- **相对强度特征**：相对于创业板指数的强弱指标、相对强度一致性
- **季节性特征**：月份、季度开始和年底标记
- **组合特征**：根据市场环境动态生成的特征组合

### 4.2 市场环境适应特征

不同市场环境下的特征重点：

| 市场类型 | 重点特征 | 特征权重分配 |
|---------|---------|------------|
| 牛市环境 | 动量和相对强度 | 动量(30%)、相对强度(30%)、趋势(20%) |
| 震荡市场 | 相对强度和波动性 | 相对强度(35%)、波动性(20%)、成交量(20%) |
| 熊市环境 | 波动率和相对强度 | 波动性(30%)、相对强度(25%)、趋势(15%) |

## 5. 使用方法

### 5.1 基本使用

```python
from to.train_sector_models import SectorModelTrainer

# 创建训练器实例
trainer = SectorModelTrainer()

# 单个板块模型训练
result = trainer.train_sector_model(
    sector_code="TGN人工智能",  # 板块代码
    start_date="20230101",     # 训练开始日期
    end_date="20230630"        # 训练结束日期
)

# 批量训练多个板块
sectors = ["TGN人工智能", "TGN医疗器械", "TGN新能源"]
results = trainer.train_all_sectors(
    sector_list=sectors,
    start_date="20230101",
    end_date="20230630",
    max_workers=4  # 并行训练的进程数
)
```

### 5.2 命令行使用

```bash
# 训练单个板块模型
python -m to.train_sector_models --mode train --sector TGN人工智能 --start_date 20230101 --end_date 20230630

# 训练所有板块模型
python -m to.train_sector_models --mode train --train_mode rotation  --start_date 20230601 --end_date 20240630 --max_workers 4 --use_lnn

# 进行预测
python -m to.train_sector_models --mode predict --date 20230701 --top_n 5
```

### 5.3 回测使用

```python
# 准备回测数据
backtest_data = trainer.prepare_backtest_data(
    sector_codes=["TGN人工智能", "TGN医疗器械", "TGN新能源"],
    start_date="20230701",
    end_date="20230831"
)

# 分析回测结果
for date, data in backtest_data.items():
    print(f"日期: {date}")
    print(f"市场状态: {data['market_status']['market_type']}")
    print(f"推荐板块: {data['top_sectors']}")
    print(f"市场适应板块: {data['market_adapted_sectors']}")
```

## 7. 注意事项

1. **数据准备**：确保板块特征数据和市场状态数据已正确生成
2. **特征选择**：不同板块可能有不同的有效特征，建议通过特征重要性分析优化
3. **回测验证**：训练模型后应进行充分的回测验证，避免过拟合
4. **市场环境适应**：市场风格变化较大时，应考虑重新训练模型
5. **时间窗口选择**：选择合适的训练窗口，太长可能捕捉不到最新市场特性，太短可能样本不足
