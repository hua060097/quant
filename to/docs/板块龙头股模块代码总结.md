# 板块龙头股分析模块代码总结

## 1. 模块概述

`sector_leading_stock.py` 是一个专门用于分析板块龙头股并计算相关特征的模块。该模块主要功能包括：

- 识别板块内的龙头股
- 计算板块热度指数
- 分析板块内股票的涨跌停情况
- 计算换手率分布特征
- 生成板块风格和聚合指标
- 管理龙头股特征的缓存机制

## 2. 代码结构

### 2.1 主要类

- **SectorLeadingStocksAnalyzer**：核心分析器类，包含所有龙头股识别和特征计算逻辑
  - **StockDataAccessor**：内部辅助类，提供类似字典的数据访问接口

### 2.2 主要功能模块

1. **数据加载**
   - `_batch_load_stocks_data`：批量加载股票数据
   - `_load_trading_calendar`：加载交易日历

2. **龙头股识别**
   - `_identify_leading_stocks`：单日龙头股识别（主要方法）
   - `_identify_leading_stocks_by_date_range`：日期范围龙头股识别（兼容旧方式）
   - `identify_leading_stocks`：外部调用接口

3. **特征计算**
   - `process_sector_data`：处理单个板块数据并计算特征
   - `_calculate_sector_heat`：计算板块热度指数
   - `_calculate_sector_aggregate_metrics`：计算板块聚合指标

4. **批量处理**
   - `batch_process_sectors`：批量处理多个板块
   - `_process_sector_with_optimized_data_loading`：优化数据加载的单板块处理

5. **缓存管理**
   - `_save_to_cache`/`_load_from_cache`：缓存操作
   - `_save_results_to_cache`：保存处理结果到缓存
   - `_merge_sector_results`：合并板块所有日期的结果

6. **辅助功能**
   - `_calculate_consecutive_limit_days`：计算连续涨停天数
   - `_calculate_amplitude`：计算股票振幅
   - `_is_broken_limit`：判断是否涨停破板
   - `_is_bse_stock`：识别北交所股票

## 3. 废弃代码识别

在最近的代码清理中，移除了一些未使用或冗余的函数：

1. **已移除的函数**
   - `_calculate_sector_features`：曾用于计算板块特征，现已集成到其他方法中
   - `_handle_special_stock_status`：曾用于处理特殊股票状态，相关功能已集成到数据加载流程
   - `_get_stock_daily_data_for_leading`：曾用于获取龙头股数据，现已简化直接使用通用数据加载方法
   - `_calculate_sector_style_features`：曾用于计算板块风格特征，已移除

2. **保留但可能冗余的方法**
   - `_identify_leading_stocks_by_date_range`：旧版本的日期范围处理方法，为保持兼容性而保留

## 4. 外部调用方式

### 4.1 获取板块龙头股

```python
from to.sector_leading_stock import SectorLeadingStocksAnalyzer

# 初始化分析器
analyzer = SectorLeadingStocksAnalyzer()

# 方式1：获取指定日期的板块龙头股
leading_stocks = analyzer.identify_leading_stocks(
    sector_code="TGN半导体", 
    date="20240101",
    lookback_days=20,  # 回溯天数
    top_n=5  # 返回前N名龙头股
)

# 返回格式: [(股票代码1, 得分1), (股票代码2, 得分2), ...]
```

### 4.2 为特征添加龙头股指标

```python
# 已有特征DataFrame
features_df = pd.DataFrame(...)

# 添加龙头股相关指标
enhanced_df = analyzer.add_sector_leading_indicators(
    features_df=features_df,
    sector_code="TGN半导体",
    date="20240101"
)

# 添加的指标包括：
# - leading_stock_count: 龙头股数量
# - high_elasticity_count: 高弹性标的数量
# - limit_up_count: 涨停股数量
# - sector_heat_index: 板块热度指数
# 等...
```

### 4.3 加载已处理的特征数据

```python
# 加载某板块的全部龙头股特征（历史数据）
features_df = analyzer.load_leading_stocks_features(sector_code="TGN半导体")
```

### 4.4 批量处理多个板块

```python
# 批量处理一段时间内的多个板块
analyzer.batch_process_sectors(
    sector_list=["TGN半导体", "TGN新能源", "TGN人工智能"],
    date_range=["20240101", "20240102", "20240103"]
)
```

## 5. 数据流程

板块龙头股处理的主要数据流程如下：

1. **数据加载**：
   - 获取板块股票列表 → 批量加载股票数据 → 处理数据格式

2. **特征计算**：
   - 计算每只股票的指标 → 评分并排序 → 识别龙头股

3. **结果保存**：
   - 保存到缓存 → 合并多日期结果 → 输出最终特征

## 6. 特征数据详细说明

### 6.1 板块特征数据结构

板块龙头股模块生成的特征数据主要保存为JSON/Parquet格式，结构如下：

```
{
    "sector_code": "板块代码",
    "date": "分析日期(YYYYMMDD)",
    "analyzed_time": "分析时间",
    "stock_count": 板块内股票总数,
    "limit_up_counts": {
        "total": 涨停股总数,
        "first_limit": 首板数量,
        "second_limit": 二板数量,
        "third_limit": 三板数量,
        "fourth_limit": 四板数量,
        "fifth_plus_limit": 五板及以上数量,
        "broken_limit": 炸板(涨停打开)数量
    },
    "turnover_distribution": {
        "high": 高换手(>10%)数量,
        "medium": 中等换手(5-10%)数量,
        "low": 低换手(<5%)数量
    },
    "market_cap_distribution": {
        "large": 大市值股(>100亿)数量,
        "medium": 中等市值股(20-100亿)数量,
        "small": 小市值股(<20亿)数量
    },
    "leading_stocks": [龙头股列表],
    "high_elasticity_stocks": [高弹性标的列表],
    "limit_up_stock_codes": [涨停股票代码列表],
    "heat_index": 板块热度指数,
    "next_day_premium": {
        "avg_open_premium": 平均开盘溢价,
        "max_open_premium": 最大开盘溢价,
        "premium_stocks": [溢价股票详情]
    }
}
```

### 6.2 主要特征指标说明

#### 基础统计特征

| 特征名称 | 数据类型 | 说明 |
|---------|--------|------|
| `stock_count` | 整数 | 板块内股票总数 |
| `limit_up_ratio` | 浮点数 | 涨停股占比 (limit_up_counts.total / stock_count) |
| `high_turnover_ratio` | 浮点数 | 高换手股占比 (turnover_distribution.high / stock_count) |
| `leading_stock_ratio` | 浮点数 | 龙头股占比 (leading_stocks长度 / stock_count) |

#### 龙头股识别特征

| 特征名称 | 数据类型 | 说明 |
|---------|--------|------|
| `leading_stocks` | 列表 | 龙头股列表，每项为(股票代码,得分)元组 |
| `high_elasticity_stocks` | 列表 | 北交所涨停标的列表(北交所涨停幅度为30%) |
| `top_leading_codes` | 字符串 | 前3名龙头股代码，逗号分隔 |
| `high_elasticity_codes` | 字符串 | 高弹性标的代码，逗号分隔 |

#### 涨停分布特征

| 特征名称 | 数据类型 | 说明 |
|---------|--------|------|
| `limit_up_counts.total` | 整数 | 涨停股总数 |
| `limit_up_counts.first_limit` | 整数 | 首板数量 |
| `limit_up_counts.second_limit` | 整数 | 二板数量 |
| `limit_up_counts.third_limit` | 整数 | 三板数量 |
| `limit_up_counts.fourth_limit` | 整数 | 四板数量 |
| `limit_up_counts.fifth_plus_limit` | 整数 | 五板及以上数量 |
| `limit_up_counts.broken_limit` | 整数 | 炸板(涨停打开)数量 |
| `limit_up_stock_codes` | 列表 | 涨停股票代码列表 |

#### 换手率分布特征

| 特征名称 | 数据类型 | 说明 |
|---------|--------|------|
| `turnover_distribution.high` | 整数 | 高换手率(>10%)股票数量 |
| `turnover_distribution.medium` | 整数 | 中等换手率(5-10%)股票数量 |
| `turnover_distribution.low` | 整数 | 低换手率(<5%)股票数量 |

#### 市值分布特征

| 特征名称 | 数据类型 | 说明 |
|---------|--------|------|
| `market_cap_distribution.large` | 整数 | 大市值股(>100亿)数量 |
| `market_cap_distribution.medium` | 整数 | 中等市值股(20-100亿)数量 |
| `market_cap_distribution.small` | 整数 | 小市值股(<20亿)数量 |

#### 热度指数相关特征

| 特征名称 | 数据类型 | 说明 |
|---------|--------|------|
| `heat_index` | 浮点数 | 板块热度指数(0-100) |

热度指数计算权重：
- 龙头股数量: 30%
- 涨停数量: 30%
- 连板涨停数量: 20%
- 换手率分布: 10%
- 高换手率比例: 10%
- 高弹性标的(额外): 5%
- 溢价情况(额外): 5%

#### 次日溢价特征

| 特征名称 | 数据类型 | 说明 |
|---------|--------|------|
| `next_day_premium.avg_open_premium` | 浮点数 | 涨停股次日平均开盘溢价(%) |
| `next_day_premium.max_open_premium` | 浮点数 | 涨停股次日最大开盘溢价(%) |
| `next_day_premium.premium_stocks` | 列表 | 溢价详情，每项包含股票代码和溢价率 |

#### 板块聚合指标

| 特征名称 | 数据类型 | 说明 |
|---------|--------|------|
| `avg_daily_return` | 浮点数 | 板块平均日收益率 |
| `volatility` | 浮点数 | 板块波动率 |
| `max_drawdown` | 浮点数 | 板块最大回撤 |
| `up_days_ratio` | 浮点数 | 上涨天数比例 |
| `momentum_5d` | 浮点数 | 5日动量 |
| `momentum_10d` | 浮点数 | 10日动量 |
| `relative_strength_index` | 浮点数 | 相对强弱指数(RSI) |

### 6.4 数据存储格式与位置

- **缓存数据**：保存在`to/local_data/features_cache/leading_stocks`目录
  - 日度缓存: `daily/{sector_code}_{date}.parquet`
  - 股票缓存: `stocks/{stock_code}_leading.parquet`

- **特征输出**：保存在`to/local_data/sector_features_leading`目录
  - 完整特征: `{sector_code}/{sector_code}_leading_stocks.parquet`
  - 最新数据: `{sector_code}/{sector_code}_leading_stocks_latest.csv`(仅含最近30天)
