# 量化交易板块轮动高级特征使用说明

## 引言

本文档详细介绍了为板块轮动策略开发的高级特征集，这些特征旨在增强模型的预测能力和策略的稳健性。板块轮动作为一种重要的量化投资策略，通过捕捉不同行业板块在不同市场周期中的相对表现差异来获取超额收益。本文将解释各项高级特征的计算方法、使用场景以及如何有效组合这些特征以构建更加完善的板块轮动策略。

## 特征分类概览

板块轮动高级特征主要分为以下几类：

1. **趋势特征**：描述价格趋势的强度、持续性和方向
2. **动量特征**：衡量价格变动的速度和加速度
3. **波动率特征**：测量价格波动的剧烈程度和稳定性
4. **相对强度特征**：评估板块与大盘或其他板块的相对表现
5. **成交量特征**：分析交易活跃度及其与价格关系
6. **综合技术指标**：整合多维度信息的复合指标
7. **板块轮动专用特征**：为捕捉板块轮动机会专门设计的特征

## 核心特征详解

### 均线关系特征

均线关系特征通过计算不同周期均线之间的相对位置和比率，为趋势判断提供基础：

```
ma5_10_ratio: MA5/MA10的比值，大于1表示短期走强
ma5_20_ratio: MA5/MA20的比值，反映短中期趋势关系
ma20_60_ratio: MA20/MA60的比值，反映中长期趋势关系
ma60_120_ratio: MA60/MA120的比值，反映超长期趋势关系
```

**应用场景**：均线比率特征在板块轮动中可有效识别趋势初期变化，尤其适合捕捉板块从弱转强的早期信号。

### 均线斜率特征

均线斜率描述均线变化的速度，能够更早地发现趋势转变：

```
ma5_slope: MA5最近5日的变化率(%)，反映短期趋势变化速度
ma20_slope: MA20最近5日的变化率(%)，反映中期趋势变化速度
```

**应用场景**：当板块的ma5_slope由负转正，且大于特定阈值时，通常意味着板块开始走强，可能是轮动进入的良好时机。

### 价格趋势方向特征

通过价格与关键均线的相对位置，构建趋势方向评分：

```
price_above_ma5/ma20/ma60: 价格是否高于对应均线
trend_direction_score: 上述三个指标的总分(0-3分)，分数越高上升趋势越明显
```

**应用场景**：板块轮动策略通常选择trend_direction_score较高的板块，尤其是从低分向高分转变的板块。

### 动量比率特征

短期与长期涨幅对比，是识别板块加速上涨的关键指标：

```
gain_20d: 近20日涨幅(%)
gain_60d: 近60日涨幅(%)
momentum_ratio: 短期涨幅与长期涨幅的比值
```

**应用场景**：momentum_ratio > 1.5时，表示板块动能加速，短期涨幅优于长期涨幅，通常是板块轮动的重要进场信号。

### 收益率加速度

描述板块收益率的变化速度，有助于识别势头强劲的板块：

```
return_5d/10d/20d: 5/10/20日收益率(%)
return_acceleration: 5日收益率减去平均日收益率，代表加速度
```

**应用场景**：return_acceleration为正且持续增加的板块，通常处于加速上涨阶段，值得优先配置。

### 趋势一致性指标

连续上涨或下跌的天数，反映趋势的稳定性：

```
consecutive_up_days: 连续上涨天数
consecutive_down_days: 连续下跌天数
```

**应用场景**：consecutive_up_days >= 3且仍有较好动能的板块，通常处于强势上涨通道中。

### 趋势效率指标

通过计算总体涨跌幅与价格波动范围的比值，评估趋势的效率：

```
trend_efficiency: 总涨跌幅与波动范围的比值，值越高表示趋势越有效率
```

**应用场景**：trend_efficiency > 0.6的板块，上涨路径更为直接，波动较小，适合稳健型板块轮动策略。

### 技术指标协同特征

结合多个技术指标的信号，提高预测准确性：

```
rsi_macd_bull_confirm: RSI大于50且MACD柱状图为正，多重指标共振看涨
macd_energy_ratio: MACD柱状图正能量与负能量比值，表示上升动能强度
```

**应用场景**：多指标共振信号强度高的板块，成功概率通常更高，可作为板块优先级排序的重要依据。

### 波动率分析特征

不同周期的波动率及其比较，有助于评估板块的稳定性：

```
volatility_20d/60d: 20/60日年化波动率(%)
volatility_ratio: 短期与长期波动率比值
volatility_rank: 当前波动率在历史分布中的百分位
```

**应用场景**：在牛市环境中，选择volatility_rank较低但收益良好的板块；在熊市环境中，关注volatility_ratio较低的防御性板块。

### 成交量价格关系特征

分析成交量与价格变动的协同关系：

```
vol_price_confirm: 量价同向变动
vol_price_diverge: 量价背离
volume_surge: 成交量突然放大
```

**应用场景**：vol_price_confirm为1且return_5d为正的板块，通常具有较强的持续上涨动能。

### 布林带特征增强

布林带宽度和位置的变化，提供了市场波动性的重要信息：

```
bb_width: 布林带宽度
bb_width_change: 布林带宽度变化率(%)
bb_pressure_support_ratio: 上方压力与下方支撑的比率
```

**应用场景**：bb_width开始扩大且bb_position > 0.7的板块，通常处于加速上涨阶段。

### 综合技术评分

基于多个技术指标计算的综合评分，提供整体技术面评估：

```
tech_score: 技术面综合评分(0-100分)
market_sentiment: 基于tech_score的市场情绪判断(bullish/neutral/bearish)
signal_strength: 交易信号强度(-100到100)
```

**应用场景**：tech_score > 70且signal_strength > 60的板块，技术面极为强势，适合作为板块轮动的首选标的。

## 板块轮动专用特征

### 相对强度指标

计算板块相对于创业板指数的表现：

```
relative_change_diff: 板块涨跌幅与创业板指数涨跌幅的差值
relative_change_ratio: 板块涨跌幅与创业板指数涨跌幅的比值
```

**应用场景**：relative_change_ratio > 1.2且持续增加的板块，相对强度显著，通常是板块轮动的理想选择。

### 成交量变化指标

分析成交量的相对变化，发现资金流向：

```
volume_change_5d: 5日成交量变化率
volume_z_score: 成交量Z得分，衡量异常程度
money_flow_ratio: 上涨日成交量与下跌日成交量比值
```

**应用场景**：money_flow_ratio > 2且volume_change_5d > 0.5的板块，表明资金持续流入，上涨动能强劲。

## 板块轮动策略中的应用

### 特征组合策略

在实际应用中，建议将不同类型的特征进行组合，形成更加稳健的选股信号。典型的组合方式包括：

1. **趋势动量组合**：结合trend_direction_score、momentum_ratio和tech_score，选择技术面全面转强的板块。

2. **相对强度筛选**：使用relative_change_ratio和return_acceleration，筛选出相对大盘强势且动能增强的板块。

3. **量价协同确认**：通过vol_price_confirm和money_flow_ratio验证资金面支持，降低虚假信号风险。

### 市场环境适应

根据不同的市场环境调整特征权重：

1. **牛市环境**：增加动量特征(momentum_ratio、return_acceleration)权重，追求高弹性板块。

2. **震荡市场**：增加相对强度特征(relative_change_ratio)权重，寻找相对强势板块。

3. **熊市环境**：增加波动率特征(volatility_ratio)和趋势稳定性特征(trend_efficiency)权重，寻找防御性板块。

## 特征重要性参考

根据经验研究，各类特征在板块轮动策略中的重要性排序(由高到低)：

1. relative_change_ratio（相对强度比率）
2. momentum_ratio（动量比率）
3. tech_score（技术评分）
4. return_acceleration（收益加速度）
5. ma5_20_ratio（均线比率）
6. trend_direction_score（趋势方向评分）
7. money_flow_ratio（资金流向比率）
8. signal_strength（信号强度）
9. volatility_ratio（波动率比率）
10. trend_efficiency（趋势效率）

## 代码示例

以下是一个使用高级特征选择最优板块的Python函数示例：

```python
def select_optimal_sectors(sector_features, market_condition='normal', top_n=3):
    """
    基于高级特征选择最优板块
    
    Args:
        sector_features: 包含各板块特征的DataFrame
        market_condition: 市场环境，可选 'bull', 'normal', 'bear'
        top_n: 返回的板块数量
        
    Returns:
        最优板块列表
    """
    # 根据市场环境设置特征权重
    if market_condition == 'bull':
        weights = {
            'momentum_ratio': 0.25,
            'return_acceleration': 0.20,
            'relative_change_ratio': 0.20,
            'tech_score': 0.15,
            'signal_strength': 0.10,
            'money_flow_ratio': 0.10
        }
    elif market_condition == 'bear':
        weights = {
            'volatility_ratio': 0.20,
            'trend_efficiency': 0.20,
            'relative_change_ratio': 0.15,
            'tech_score': 0.15,
            'bb_pressure_support_ratio': 0.15,
            'consecutive_up_days': 0.15
        }
    else:  # normal
        weights = {
            'relative_change_ratio': 0.25,
            'tech_score': 0.20,
            'momentum_ratio': 0.15,
            'trend_direction_score': 0.15,
            'money_flow_ratio': 0.15,
            'vol_price_confirm': 0.10
        }
    
    # 计算综合评分
    sector_features['composite_score'] = 0
    
    for feature, weight in weights.items():
        if feature in sector_features.columns:
            # 对特征进行标准化
            max_val = sector_features[feature].max()
            min_val = sector_features[feature].min()
            
            if max_val > min_val:
                normalized = (sector_features[feature] - min_val) / (max_val - min_val)
                sector_features['composite_score'] += normalized * weight
    
    # 返回评分最高的top_n个板块
    return sector_features.sort_values('composite_score', ascending=False).head(top_n)['sector_name'].tolist()
