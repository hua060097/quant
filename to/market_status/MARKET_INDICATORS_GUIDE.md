# 市场状态指标指南

本文档详细介绍了市场状态处理器生成的各项指标的含义和用途，这些指标用于描述市场状态并可以被模型训练使用。

## 1. 核心市场类型指标

### 市场类型编码 (market_type_code)

市场类型编码是一个两位数字，第一位表示大类，第二位表示细分类型：

| 编码 | 名称 | 描述 |
|------|------|------|
| 11 | 强势突破上涨 | 突破重要压力位，量价配合，持续性强 |
| 12 | 加速上涨 | 快速上涨，但未到过热 |
| 13 | 稳健上涨 | 均线多头排列，量价良好 |
| 21 | 盘升上涨 | 缓慢向上，成交量温和 |
| 22 | 回调上涨 | 短期回调后继续上行 |
| 23 | 整固上涨 | 高位整理后继续上行 |
| 31 | 强势盘整 | 高位盘整，支撑强 |
| 32 | 中性盘整 | 箱体震荡，方向不明 |
| 33 | 弱势盘整 | 低位盘整，压力大 |
| 41 | 盘跌下行 | 缓慢向下，暂无明显企稳 |
| 42 | 回抽下跌 | 反弹后继续下行 |
| 43 | 整固下跌 | 低位整理后继续下行 |
| 51 | 加速下跌 | 快速下跌，但未到恐慌 |
| 52 | 恐慌下跌 | 快速大幅下跌，成交量萎缩 |
| 53 | 超跌反弹 | 大幅下跌后的反弹修复 |

### 市场周期编码 (market_cycle_code)

市场周期编码表示市场所处的大周期阶段：

| 编码 | 名称 | 描述 |
|------|------|------|
| 1 | 积累期 | 底部区域，价格低迷，成交量低，但有机构悄悄建仓 |
| 2 | 上升期 | 突破上行，成交量逐渐放大，趋势确立 |
| 3 | 分配期 | 高位区域，成交量显著放大，波动加剧，机构悄悄卖出 |
| 4 | 下降期 | 明确下跌，成交量先放大后萎缩，趋势向下 |

## 2. 市场评分指标

所有评分指标都经过归一化处理，范围为0-5，其中0表示极弱/消极，5表示极强/积极。

### trend_score (趋势得分)

评估市场当前趋势的强度和方向。

**范围**：0-5
- **5分**：极强的上升趋势，多头排列明确，动能强
- **4分**：强劲上升趋势，但有轻微回调迹象
- **3分**：中等上升趋势，或高位盘整
- **2分**：弱上升趋势，或中性盘整
- **1分**：弱下降趋势，或弱势盘整
- **0分**：强烈下降趋势，空头排列明确

计算因素：
- 价格与各周期均线的关系
- 均线系统的排列形态
- MACD柱状图的方向和幅度
- 近期价格走势的方向性和一致性

### position_score (位置得分)

评估当前价格在近期波动区间中的相对位置。

**范围**：0-5
- **5分**：位于上轨突破位置，有新高潜力
- **4分**：接近上轨，但未突破
- **3分**：位于中轨上方，呈现上行趋势
- **2分**：位于中轨附近，方向不明
- **1分**：位于中轨下方，呈现下行趋势
- **0分**：位于下轨或更低，超跌状态

计算因素：
- 布林带中的相对位置
- 相对于最近高点和低点的位置
- 价格是否处于支撑或阻力位附近

### volume_score (量能得分)

评估交易量的强度和特征。

**范围**：0-5
- **5分**：成交量放大并持续，并与价格上涨配合
- **4分**：成交量稳定增长，交投活跃
- **3分**：成交量中等，略高于近期平均
- **2分**：成交量中等，与近期平均相当
- **1分**：成交量萎缩，交投不活跃
- **0分**：成交量极度萎缩，几乎无人交易

计算因素：
- 近期成交量相对于均量的水平
- 量价配合是否合理
- 成交量变化趋势

### momentum_score (动能得分)

评估价格动能和涨跌速度。

**范围**：0-5
- **5分**：强劲上升动能，快速上涨，超买但仍有动力
- **4分**：良好上升动能，上涨速度适中
- **3分**：中等上升动能，或开始减缓
- **2分**：中性动能，横盘整理
- **1分**：下降动能，开始加速下跌
- **0分**：强烈下降动能，快速下跌，超卖状态

计算因素：
- RSI指标值及变化
- MACD值及变化速度
- KDJ指标的数值和方向
- 价格变化的加速度

### volatility_score (波动得分)

评估市场波动性的大小。

**范围**：0-5
- **5分**：极高波动性，剧烈震荡，高风险高回报
- **4分**：高波动性，明显震荡
- **3分**：中等波动性，波动开始增加
- **2分**：低中等波动性，相对稳定
- **1分**：低波动性，波动很小
- **0分**：极低波动性，几乎无波动

计算因素：
- 布林带宽度
- 近期价格波动范围
- 价格变化的标准差
- 高低点之间的距离

### structure_score (结构得分)

评估价格形态的完整性和可靠性。

**范围**：0-5
- **5分**：完美的上涨结构，高点抬高，低点抬高
- **4分**：良好的上涨结构，有小幅回调
- **3分**：中性结构，可能处于形态转变过程中
- **2分**：弱趋势结构，形态不明确
- **1分**：下跌结构开始形成，低点降低
- **0分**：完整的下跌结构，高点降低，低点降低

计算因素：
- 高低点排列模式
- 是否形成特定形态（如头肩顶、双底等）
- 突破确认情况
- 支撑位和阻力位的表现

### cycle_score (周期得分)

评估市场在周期中的位置。

**范围**：0-5
- **5分**：处于上升周期初期，有望继续上涨
- **4分**：处于上升周期中期，上涨动力仍在
- **3分**：处于上升周期后期或顶部区域
- **2分**：开始转入下降周期，但尚未确认
- **1分**：处于下降周期中期
- **0分**：处于下降周期后期或底部区域

计算因素：
- 对大周期转折点的识别
- 周期指标的读数
- 价格波动的周期性特征
- 与历史周期的对比分析

### total_score (总分)

综合以上各项得分的加权平均，反映市场的整体状态。

**范围**：0-5
- **4-5分**：强势市场，适合积极做多
- **3-4分**：偏强市场，可谨慎做多
- **2-3分**：中性市场，观望或轻仓参与
- **1-2分**：偏弱市场，减仓为主
- **0-1分**：弱势市场，适当规避风险

计算方法：
```
total_score = (
    trend_weight * trend_score + 
    position_weight * position_score + 
    volume_weight * volume_score +
    momentum_weight * momentum_score +
    volatility_weight * volatility_score +
    structure_weight * structure_score +
    cycle_weight * cycle_score
) / sum_of_weights
```

其中权重根据市场环境动态调整，一般趋势得分和周期得分的权重较高。

## 3. 技术指标数据

以下原始技术指标数据也会被保存，用于进一步分析和模型训练：

### MA系列 (移动平均线)
- `ma5`: 5日移动平均线
- `ma10`: 10日移动平均线
- `ma20`: 20日移动平均线
- `ma60`: 60日移动平均线
- `ma120`: 120日移动平均线

### MACD (指数平滑异同平均线)
- `macd`: MACD线，快线(EMA12)减慢线(EMA26)
- `macd_signal`: 信号线，MACD的9日EMA
- `macd_hist`: MACD柱状图，MACD减信号线

### RSI (相对强弱指数)
- `rsi6`: 6日相对强弱指数
- `rsi12`: 12日相对强弱指数
- `rsi24`: 24日相对强弱指数

### 布林带指标
- `bb_upper`: 布林带上轨，MA20 + 2*标准差
- `bb_middle`: 布林带中轨，即20日移动平均线
- `bb_lower`: 布林带下轨，MA20 - 2*标准差
- `bb_width`: 布林带宽度，(上轨-下轨)/中轨
- `bb_position`: 价格在布林带中的相对位置，0表示在下轨，1表示在上轨

### KDJ指标
- `kdj_k`: K值，当前收盘价在最近n天的高低点范围内的相对位置
- `kdj_d`: D值，K值的移动平均
- `kdj_j`: J值，3D-2K，反映价格波动的动力

### 价格相关指标
- `support_level`: 支撑位，当前重要的价格支撑水平，价格下跌到此位置可能会获得支撑反弹
- `resistance_level`: 压力位，当前重要的价格压力水平，价格上涨到此位置可能会遇到阻力回落
- `change_percent`: 涨跌幅，相对于前一交易日的百分比变化，正值表示上涨，负值表示下跌

支撑位和压力位的判断依据：
- 历史成交密集区
- 重要均线位置（如60日均线、20日均线）
- 前期高点和低点
- 整数价位（如100元、50元等整数关口）
- 斐波那契回调位

## 4. 模型训练使用指南

在 `train_sector_models.py` 中，以下特征被用于训练预测模型：

1. **市场类型和周期特征**：
   - `market_type_code`: 市场类型编码(数值)
   - `market_cycle_code`: 市场周期编码(数值)

2. **市场评分指标**：
   - `trend_score`: 趋势得分
   - `position_score`: 位置得分
   - `volume_score`: 量能得分
   - `momentum_score`: 动能得分
   - `volatility_score`: 波动得分
   - `structure_score`: 结构得分
   - `cycle_score`: 周期得分
   - `total_score`: 总分

3. **技术指标派生特征**：
   - `price_ma_ratio`: 价格与各均线的比值
   - `ma_alignment`: 均线系统排列状况
   - `vol_ma_ratio`: 成交量与成交量均线的比值
   - `macd_trend`: MACD方向和强度
   - `rsi_trend`: RSI方向和区域
   - `bb_status`: 布林带状态指标

4. **价格支撑压力特征**：
   - `support_level`: 支撑位水平
   - `resistance_level`: 压力位水平
   - `change_percent`: 涨跌幅百分比
   - `price_to_support_ratio`: 当前价格与支撑位的比率
   - `price_to_resistance_ratio`: 当前价格与压力位的比率

通过这些特征的不同时间窗口(长期、短期)组合，可以有效地训练出预测市场未来走势的模型。
