# 板块特征生成系统 - 集成版

## 概述

集成版板块特征生成系统整合了多个特征计算模块的优点，提供了一套完整的板块特征生成解决方案。本系统具有以下特点：

- **高性能计算**：使用Numba加速、内存映射和数据压缩技术
- **全面特征计算**：支持基础特征、技术指标和增强特征
- **多进程并行**：支持多进程并行处理大量板块数据
- **增量更新**：支持增量更新特征数据，避免重复计算
- **灵活配置**：提供多种配置选项，适应不同的使用场景

## 系统架构

集成版特征生成系统包含以下主要组件：

1. **`generate_sector_features_updated.py`** - 主入口文件，提供命令行接口
2. **`integrated_feature_generator.py`** - 集成特征生成器，整合特征计算能力
3. **`technical_indicators.py`** - 技术指标计算模块，支持多种技术指标

## 支持的特征

系统支持的特征包括：

### 基础特征
- 开盘价均值、最高价均值、最低价均值、收盘价均值
- 成交量均值、成交额均值、涨跌幅均值
- 活跃股票数量、总成交额、板块股票数量

### 技术指标特征
- 移动平均线 (MA5, MA10, MA20, MA60)
- 布林带 (上轨、中轨、下轨)
- 相对强弱指数 (RSI6, RSI14)
- MACD指标 (MACD线、信号线、柱状图)
- 均线位置指标 (价格相对于均线的位置)
- 动量指标 (5日、10日)
- 量价背离指标

### 增强特征
- 短期/中期趋势强度
- 距离阶段高点/低点的百分比
- 成交量变化率
- 波动性指标 (ATR, 波动率)
- 资金流向指标 (MFI, CMF)

## 使用方法

### 基本用法

```bash
python generate_sector_features_updated.py --mode=single --sector="TGN人工智能" --days=7
```

### 处理所有板块

```bash
python generate_sector_features_updated.py --mode=all --days=30
```

### 处理特定日期范围

```bash
python generate_sector_features_updated.py --mode=date_range --start_date=20230101 --end_date=20230131
```

## 参数说明

- `--mode`: 处理模式 (single, all, recent, date_range)
- `--sector`: 板块名称 (单板块模式必选)
- `--sectors`: 多个板块名称，空格分隔
- `--start_date`: 开始日期，格式YYYYMMDD
- `--end_date`: 结束日期，格式YYYYMMDD
- `--days`: 处理最近N天的数据
- `--date`: 单个日期，格式YYYYMMDD
- `--output_dir`: 输出目录
- `--workers`: 最大工作进程数
- `--batch_size`: 每批处理的日期数量

## 性能优化

系统采用了多种性能优化技术：

1. **Numba加速**: 对计算密集型的技术指标计算使用Numba即时编译加速
2. **批量处理**: 按批次处理日期数据，减少I/O开销
3. **多进程并行**: 多个板块并行处理，充分利用多核CPU
4. **内存优化**: 及时释放不再使用的大型数据结构，降低内存占用

## 扩展性

系统设计具有良好的扩展性：

1. 可自定义新的技术指标计算方法
2. 可调整特征计算策略
3. 可定制输出格式和存储方式

## 注意事项

1. 确保依赖库已正确安装
2. 大型数据集处理时注意内存占用
3. 使用适当的工作进程数，避免系统资源耗尽

## 常见问题排查

1. 导入错误: 检查依赖模块是否已安装
2. 日期格式错误: 确保使用正确的日期格式 (YYYYMMDD)
3. 数据缺失: 检查原始数据源是否可用
4. 内存不足: 减少批处理大小或降低工作进程数
